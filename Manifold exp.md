## Единая сетка manifold-бенчмарка

Во всех основных сериях фиксировать:

\[
X\sim N(0,I_d),\qquad u=XQ,
\]

\[
z_k=u_k+\frac c2u_{m+k}^2,
\qquad
f(X)=\frac12\sum_{k=1}^m z_k^2,
\]

\[
Y=\frac{f(X)-\mathbb Ef(X)}
{\operatorname{sd}(f(X))}
+\sigma\varepsilon,
\qquad
\varepsilon\sim N(0,1).
\]

Алгоритмически фиксировать `support=local`, `scale_boundary=raise`. Это позволяет менять только статистические параметры задачи.

### Число повторов

Чтобы сохранить масштаб протокола Спокойного:

\[
\boxed{250\text{ seed на конфигурацию}}
\]

то есть

\[
23\times250=\boxed{5750\text{ запусков}}.
\]

Для разработки можно использовать те же точки с 30 seed:

\[
23\times30=690
\]

запусков, а затем прогнать 250 seed для итогового результата.

### Фиксированные параметры estimator

Для всей сетки я бы не менял:

```text
estimator       = manifold
solver          = cg
N_J             = 40
N_phi           = 40
N_loc           = 80
N_lin           = 200
N_manifold      = 10
sync_steps      = 3
lambda_manifold = 0.5
cg_tol          = 1e-6
support         = local
scale_boundary  = raise
batch_size      = 32
h_min           = 3 * mean(std(X)) / sqrt(n)
a               = 2^(1/m)
```

`broad` и `scale_boundary=stop` лучше оставить отдельными диагностическими A/B-сериями, а не включать в эту сетку. Иначе ты начинаешь одновременно тестировать статистическую сложность задачи и tuning самого estimator.
