# LOO1-WLS-ADP Implementation Plan

> **For Antigravity:** REQUIRED SUB-SKILL: Execute task-by-task via TDD (tests first via hydrogen agent, core implementation, full verification, paired benchmark & hostile audit).

**Goal:** Add a production-grade, vectorized, streaming-capable opt-in multi-index estimator `estimator="loo1_wls"` (`LOO1-WLS-ADP` with subcritical anisotropy spectrum $\beta \in (0, 1)$ and $R^{-1}$-preconditioned Grassmann optimization) on branch `feat/loo1-wls-adp`.

**Architecture:** Isolate estimator configuration in `ADP/core/loo1_wls.py`, flat-CSR vectorized 2-DGEMM evaluation and streaming `distance2`-free helpers in `ADP/engine/common/loo1_wls.py`, and the $R^{-1}$-preconditioned Grassmann solver in `ADP/solver/loo1_wls.py`. Dispatch cleanly from `ADP/engine/common/index_fit.py` and `ADP/core/multi/ADP_multi_index.py` when `config.estimator == "loo1_wls"`, leaving `estimator="new"` and `"legacy"` untouched.

**Tech Stack:** Python >= 3.11, NumPy, SciPy (`scipy.linalg.eigh`), pytest, ruff.

### Task 2: Core Implementation (`core-impl`)

**Files:**
- Create: `ADP/core/loo1_wls.py`
- Create: `ADP/engine/common/loo1_wls.py`

- Modify: `ADP/engine/common/index_fit.py`
- Modify: `ADP/core/multi/ADP_multi_index.py`
- Modify: `ADP/__init__.py`

**Key mathematical & numerical invariants:**
- `LOO1WLSConfig` defaults: `spectrum_exponent=0.5`, `ridge=1e-4`, `leverage_cap=0.85`, `smooth_cap_eps=0.0`, `preconditioner_reg=1e-3`, `min_neighbors=None` (defaults to `m + 2`), `center_chunk=512`, `stream_distances=None`, `stream_distance_threshold=4_000_000`, `max_steps=25`, `tol=1e-6`, `armijo_c1=1e-4`, `max_line_search=14`.
- `evaluate_loo1_wls` processes centers in chunks of `center_chunk` using `np.add.reduceat`, `np.repeat`, batched `np.linalg.solve` (never `np.linalg.inv`!), and `np.bincount` for scatter-add into `Gamma (n, m)`, followed by `X.T @ Gamma`.
- `solve_loo1_wls` computes $R = \sum_{j \in \mathcal{A}} N_j c_j c_j^\top$, `tau = preconditioner_reg * max(1.0, float(np.sum(np.maximum(vals, 0.0))))`, polar SVD retraction, Armijo backtracking, and returns `HPAOResult` with `index` shaped `(m, d)` (row-orthonormal) and `coefficients` shaped `(total_centers, m)`.
- `index_fit.py` routes `estimator="loo1_wls"` to `_fit_multi_loo1_wls`, skipping random sketch generation completely, recording `mean_loo1_loss` as `err` and `response_err` in `trace`, updating spectrum with `subcritical_eigenvalues`, and respecting `stream_distances`.
