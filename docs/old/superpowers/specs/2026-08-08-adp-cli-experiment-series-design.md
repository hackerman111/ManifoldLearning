# Серии экспериментов в uppercase ADP CLI

## Цель

Расширить `ADP/cli.py`, чтобы один вызов запускал один и тот же набор параметров
несколько раз с последовательными seed, сохранял результаты каждого запуска в
CSV и автоматически создавал диагностические графики по внешним итерациям.

## Интерфейс CLI

Существующие аргументы данных и `ADP_Config` сохраняются. Добавляются:

- `--runs N` — число запусков, по умолчанию `1`;
- `--output-dir PATH` — корень результатов, по умолчанию
  `ADP/experiment_outputs`.

Аргумент `--seed S` задаёт первый seed. Запуск с индексом `i` использует
`S + i` и для генерации данных, и для `ADP_Config.seed`.

Пример:

```bash
python ADP/cli.py --runs 10 --output-dir ADP/experiment_outputs
```

Каждый вызов создаёт отдельный каталог серии с временной меткой, поэтому
предыдущие результаты не перезаписываются.

## Класс Scenario

Добавляется dataclass `Scenario`, содержащий параметры синтетических данных,
базовый seed, число запусков, шаблон `ADP_Config` и каталог вывода. Класс:

1. создаёт независимые данные для каждого seed;
2. создаёт отдельную модель с соответствующим `ADP_Config.seed`;
3. запускает `fit(X, Y)`;
4. связывает `beta_true` с `model.result_` и вычисляет начальный и финальный
   абсолютные косинусы;
5. преобразует `result.trace` в строки истории;
6. сохраняет строки сразу после каждого запуска;
7. после серии строит графики и возвращает каталог результатов.

Ошибка одного запуска записывается в итоговую таблицу и не отменяет оставшиеся
запуски. После завершения CLI возвращает ненулевой код, если хотя бы один запуск
завершился ошибкой.

## CSV

В каталоге серии создаются две таблицы:

- `runs.csv` — одна строка на запуск: индекс, seed, параметры данных и ADP,
  статус, причина остановки, число итераций, начальный и финальный абсолютные
  косинусы, текст ошибки;
- `outer_iterations.csv` — одна строка на внешнюю итерацию: индекс запуска,
  seed, `outer_k`, `h_k`, `rho_k`, `cosine_abs`, `mean_mass`, направление beta
  и скалярные диагностические поля из `result.trace`.

Таблицы создаются до вычислений и дописываются после каждого запуска. Это
сохраняет уже завершённые результаты при последующей ошибке или остановке.

## Графики

После серии из `outer_iterations.csv` автоматически создаются:

- `quality_vs_outer_iteration.png` — абсолютный косинус, диапазон Y `[0, 1]`;
- `bandwidth_vs_outer_iteration.png` — `h_k`, логарифмическая ось Y;
- `rho_vs_outer_iteration.png` — `rho_k`, диапазон Y `[0, 1]`.

Для каждого `outer_k` показываются медиана и полоса квантилей 5–95% по
запускам. Используются параметры из
`main:adp/evaluation/single_index/reports.py` и
`main:adp/evaluation/single_index/plots.py`: размер `10.5 × 6.2`, маркеры на
медиане, полупрозрачная полоса, ADP-палитра и стиль осей, русские подписи,
сохранение с `dpi=300`. Если для графика нет конечных значений, создаётся
рисунок с сообщением об отсутствии наблюдений.

## Проверка

Точечная проверка запускает CLI с двумя небольшими экспериментами и проверяет:

- успешное завершение команды;
- две строки в `runs.csv`;
- обязательные столбцы и строки в `outer_iterations.csv`;
- наличие трёх непустых PNG;
- соответствие `cosine_abs` сохранённому beta и истинному направлению.
