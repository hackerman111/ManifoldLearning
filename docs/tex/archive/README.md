# Архив TeX из Vlad_EDR_M

Здесь сохранены пути исторических документов из M. Точные копии уже имеющихся
в `EDR_code/SVD` и `EDR_code/tex` документов представлены относительными
символическими ссылками. Так сохраняются старые ссылки и один редактируемый
источник для одинакового содержимого.

`ADP_Grassmann_current.tex` — самостоятельная версия из M. Она отличается
от [tex/ADP_Grassmann_current.tex](../ADP_Grassmann_current.tex), для которого
сохранена собственная запись проверки. Эти версии не объединялись по формулам.

Основные маршруты:

- [SVD и единая теория](../../SVD/README.md).
- [Синтез проверенных идей](../../SVD/AI_research_synthesis.tex).
- [Исходные multi-index формулы](../multiindex.tex);
  `multiindex_1.tex` является точной копией того же текста.
- [История исследований](../../SVD/GRASSMANN_IMPROVEMENT_HISTORY.md).
- `argon.md`, `cladue.md` и другие исходные заметки сохранены как исторический
  материал; они сами по себе не подтверждают результаты экспериментов.

Карта хешей и исходных путей — в [манифесте](../../integration/vlad_edr_m_20261026/IMPORT_MANIFEST.json).
