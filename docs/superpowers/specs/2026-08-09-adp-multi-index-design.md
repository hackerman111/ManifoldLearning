# ADP multi-index: дизайн реализации

## Цель

Реализовать независимую multi-index модель по текущему single-index pipeline и
multi-index разделу `tex/manifold_v2.tex`. Не строить локализующий тензор
размера `d x d`.

## API и формы

```python
model = ADP_multi_index(index_dim=m, config=config, solver=solver)
model.fit(X, Y)
Z = model.transform(X)
```

- `X.shape == (n, d)`, `Y.shape == (n,)`;
- `1 <= index_dim < d`;
- `basis_.shape == (d, m)` и `transform(X) == X @ basis_`;
- обозначение из TeX связано с API как `P = basis_.T`, поэтому
  `P.shape == (m, d)` и `P @ P.T == I_m`.

`ADP_multi_index_result` хранит начальный и итоговый базисы, trace, причину
остановки и, при наличии истинного базиса, нормированное расстояние между
ортогональными проекторами:

\[
d(B, B_*) = \frac{\|BB^\top-B_*B_*^\top\|_F}{\sqrt{2m}}.
\]

## Инициализация

Поддерживаются существующие значения `ADP_Config.index_init`:

- `local`: локальные линейные оценки градиента в центрах, затем первые `m`
  правых сингулярных векторов матрицы градиентов;
- `random`: гауссова матрица `(d, m)`, ортонормированная QR-разложением.

Обе ветви возвращают конечный ортонормированный базис `(d, m)` и используют
локальный генератор `numpy.random.Generator` из `config.seed`.

## Matrix-free локализация

Состояние локализации состоит только из `basis (d,m)`, `eigenvalues (m,)`,
`alpha` и `h`. Матрицы `T_k` и `T_k^2` не создаются.

Для разности `v = X_i - x_j` аргумент ядра вычисляется напрямую:

\[
\|T_kv\|^2 = h_k^{-2}\left[
\alpha_k^2(\|v\|^2-\|P_kv\|^2)
+(P_kv)^\top\Lambda_k(P_kv)
\right].
\]

Веса вычисляются блоками центров. Рабочая память локализации составляет
`O(Bn + md)`, где `B` — `batch_size`.

Случайные направления с требуемой ковариацией генерируются без плотной
матрицы: гауссов вектор раскладывается на ортогональную базису часть и
низкоранговую часть внутри базиса, масштабированную `sqrt(eigenvalues)`.

После уменьшения `h` параметр `alpha` выбирается бинарным поиском как
наибольшее значение в `[0, 1]`, сохраняющее среднюю локальную массу не меньше
`N_loc`. Если условие невозможно даже при `alpha=0`, обучение завершается с
`stop_reason="local_mass_limit"`.

## Multi-index LSMR

Текущий `ADP/single_index/solvers/LSMR.py` сохраняет поддержку одномерного
индекса и принимает также начальный базис `(d, m)`.

Один внутренний шаг:

1. При фиксированном базисе независимо оценивает локальные коэффициенты
   `(J, m)` ridge-регрессией.
2. При фиксированных коэффициентах обновляет матрицу `(d, m)` одним
   `scipy.sparse.linalg.LinearOperator`; плотная design-матрица не создаётся.
3. Строит структурную матрицу только в факторизованном виде, вычисляет её
   ненулевую `m x m` спектральную часть и возвращает ортонормированный базис и
   `m` неотрицательных собственных значений.

Собственные значения передаются через diagnostics solver'а и используются
следующим шагом локализации. Неконечные значения, нулевой ранг и неверные
формы завершаются явной ошибкой.

## Поток `fit`

1. Проверить данные и параметры; выбрать центры и начальный базис.
2. Найти исходную изотропную ширину `h_0`.
3. Сгенерировать направления, вычислить блоковые веса и общие
   `ADP_Statistics`.
4. Запустить LSMR и получить базис, коэффициенты и собственные значения.
5. Сохранить диагностику; уменьшить `h`, найти `alpha` и обновить
   matrix-free локализацию.
6. При остановке присвоить `basis_`, `eigenvalues_`, `coefficients_`,
   `trace_`, `result_`, `effective_parameters_` и `n_features_in_`.

Как и single-index модель, `fit` возвращает `self`; `transform` до обучения
поднимает `RuntimeError`.

## Границы изменения и проверка

Новый общий базовый класс, отдельный публичный statistics API и плотный
тензор не добавляются. Меняются только multi-index модель, минимально
обобщаемые функции calculus/validation, LSMR и пакетные экспорты.

Одна сфокусированная тестовая группа проверяет:

- ортонормированность обеих инициализаций;
- совпадение matrix-free квадратичной формы с явной формулой на малом размере;
- сохранение single-index контракта LSMR;
- multi-index synthetic smoke, формы результата и конечность diagnostics.
