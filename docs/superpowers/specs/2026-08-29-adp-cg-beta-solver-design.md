# Matrix-free CG-солвер шага beta в ADP

## Цель и границы

Добавить отдельный baseline-солвер для single-index alternating optimization.
При фиксированных локальных наклонах `slopes` он обновляет вектор `beta`
методом сопряжённых градиентов. Текущий HPAO-LSMR остаётся солвером по
умолчанию; CG подключается через существующий аргумент
`ADP_Solver(..., solver=cg)`.

Multi-index, CLI-переключатель и изменение статистического оценивателя в эту
задачу не входят.

## Математический контракт

Для `U.shape == (J, p, d)`, `I.shape == (J, p)` и положительных внешних весов
`mass.shape == (J,)` один глобальный подшаг при фиксированных `slopes` решает

\[
\min_b \frac12 \sum_j c_j\|I_j-\ell_jU_jb\|^2
       +\frac{\lambda}{2}\|b-\beta_{prior}\|^2.
\]

CG применяется к симметричной системе

\[
\left(\sum_j c_j\ell_j^2U_j^TU_j+\lambda I\right)b
=\sum_j c_j\ell_jU_j^TI_j+\lambda\beta_{prior}.
\]

Матрица размера `d x d` не создаётся. `LinearOperator` вычисляет её действие
через плотные статистики `U`; диагональный Jacobi-предобуславливатель также
считается без промежуточного `d x d` массива. После шага индекс нормируется с
согласованием знака, а локальные наклоны пересчитываются точным least-squares
шагом.

Это изменение класса `NUMERICAL`: конечная квадратичная подзадача совпадает с
текущей, но LSMR заменяется CG над normal operator. Вариант изолирован, потому
что normal operator ухудшает обусловленность по сравнению с LSMR.

## API и диагностика

Новый модуль `ADP/solver/CG.py` предоставляет:

- `cg(beta_init, U, I, **settings) -> np.ndarray` — совместимый адаптер для
  `ADP_Solver`;
- `solve(...) -> HPAOResult` — полный результат с индексом, локальными
  коэффициентами и диагностикой.

Поддерживаются `mass`, `lambda_prox`, `max_steps`, `tol` и `cg_maxiter`.
Солвер принимает только `beta.shape == (d,)`. Он отвергает нечисловые,
нефинитные и несовместимые входы, нулевой индекс, некорректную диагональ
предобуславливателя и любой незавершившийся или несертифицированный CG-шаг.

Диагностика содержит число AO- и CG-итераций, SciPy status, относительный
линейный residual, историю objective, норму риманова градиента и флаг
сходимости AO. Невалидный результат не заменяется предыдущим индексом.

## Проверка

Один deterministic reference-тест сравнивает matrix-free CG-подшаг с
`np.linalg.solve` на малой положительно определённой системе, проверяет
остаток, нормировку и неувеличение ADP objective. Второй тест запускает
публичный `ADP_Solver` с `solver=cg` и проверяет конечный единичный индекс.

Настроенные Ruff, Pyright и pytest запускаются после реализации. Новых
зависимостей и performance-утверждений не добавляется.
