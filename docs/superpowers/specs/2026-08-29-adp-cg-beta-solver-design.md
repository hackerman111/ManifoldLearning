# Matrix-free CG-солвер шага beta в ADP

## Цель и границы

Добавить отдельный baseline-солвер для single- и multi-index alternating
optimization. При фиксированных локальных коэффициентах он обновляет вектор
или матрицу `beta` методом сопряжённых градиентов. Текущий HPAO-LSMR остаётся
солвером по умолчанию; CG подключается через существующий аргумент solver.

CLI-переключатель и изменение статистического оценивателя в эту задачу не
входят.

## Математический контракт

Для `U.shape == (J, p, d)`, `I.shape == (J, p)` и положительных внешних весов
`mass.shape == (J,)` один глобальный подшаг при фиксированных `slopes` решает

\[
\min_b \frac12 \sum_j c_j\|I_j-\ell_jU_jb\|^2
       +\frac{\lambda}{2}\|b-\beta_{prior}\|^2.
\]

CG применяется к симметричной системе

\[
\left(\sum_j c_j\ell_j^2U_j^TU_j+\lambda I\right)b
=\sum_j c_j\ell_jU_j^TI_j+\lambda\beta_{prior}.
\]

Матрица размера `d x d` не создаётся. `LinearOperator` вычисляет её действие
через плотные статистики `U`; диагональный Jacobi-предобуславливатель также
считается без промежуточного `d x d` массива. После шага индекс нормируется с
согласованием знака, а локальные наклоны пересчитываются точным least-squares
шагом.

Для multi-index `beta.shape == (m, d)` и локальных коэффициентов
`L.shape == (J, m)` совместно решается задача

\[
\min_B \frac12 \sum_j c_j\|I_j-U_jB^T L_j\|^2
       +\frac{\lambda}{2}\|B-B_{prior}\|_F^2.
\]

CG применяется к normal operator над `vec(B)` размера `m*d`. Его действие
вычисляется последовательностью `U_j B^T L_j` и её точным сопряжённым
действием. Полная матрица `(m*d) x (m*d)` не создаётся. Jacobi-диагональ для
координаты `(q, r)` равна

\[
\lambda + \sum_{j,p} c_j L_{jq}^2 U_{jpr}^2.
\]

Joint-решение сохраняет перекрёстные блоки `L_{jq}L_{js}`. Независимое решение
строк `B` их теряет и поэтому не является допустимым вариантом той же задачи.
После CG существующий gauge-fix ортонормирует строки и одновременно
преобразует локальные коэффициенты, сохраняя fitted values; затем выполняется
точный локальный refit.

Это изменение класса `NUMERICAL`: конечная квадратичная подзадача совпадает с
текущей, но LSMR заменяется CG над normal operator. Вариант изолирован, потому
что normal operator ухудшает обусловленность по сравнению с LSMR.

## API и диагностика

Новый модуль `ADP/solver/CG.py` предоставляет:

- `cg(beta_init, U, I, **settings) -> np.ndarray` — совместимый адаптер для
  `ADP_Solver`;
- `solve(...) -> HPAOResult` — полный результат с индексом, локальными
  коэффициентами и диагностикой.

Поддерживаются `mass`, `lambda_prox`, `max_steps`, `tol` и `cg_maxiter`.
Солвер принимает `beta.shape == (d,)` или полноранговую матрицу `(m, d)`. Он
отвергает нечисловые, нефинитные и несовместимые входы, нулевой или
вырожденный индекс, некорректную диагональ предобуславливателя и любой
незавершившийся или несертифицированный CG-шаг.
`lambda_prox` должен быть строго положительным: только тогда normal operator
гарантированно положительно определён, как требует SciPy CG. Для
нерегуляризованного шага остаётся HPAO-LSMR.

Диагностика содержит число AO- и CG-итераций, SciPy status, относительный
линейный residual, историю objective, норму риманова градиента и флаг
сходимости AO. Невалидный результат не заменяется предыдущим индексом.

## Проверка

Один deterministic reference-тест сравнивает matrix-free CG-подшаг с
`np.linalg.solve` на малой положительно определённой системе, проверяет
остаток, нормировку и неувеличение ADP objective. Второй тест запускает
публичный `ADP_Solver` с `solver=cg` и проверяет конечный единичный индекс.

Multi-index reference-тест явно строит малый joint design operator, сравнивает
CG с `np.linalg.solve`, проверяет симметрию оператора, ортонормальность строк,
неувеличение objective и инвариантность к ортогональной смене базиса внутри
того же подпространства. Ограничение итераций должно завершаться явной
ошибкой, а не возвратом предыдущего индекса.

Настроенные Ruff, Pyright и pytest запускаются после реализации. Новых
зависимостей и performance-утверждений не добавляется.
