# Разреженность функционалов и применимость sparse solver-ов

Аудит измеряет структурные нули точных матриц текущих функционалов. Он не
изменяет estimator и не сравнивает wall-clock solver-ов.

- Задач: 9/10;
  каждая задача включает single, multi и manifold.
- Вещественная точность: float64; near-zero считается как
  `0 < |a| <= 1e-12 max(|A|)` и не приравнивается к структурному нулю.
- Git: `6a540eedd4b5c98f1fae2698960e5aa89b931a36`; dirty status сохранён в JSON.

В manifold строка `Матрица` относится к B-system одного target;
плотности являются квантилями по target-ам всех задач tier-а; колонка
CSR graph — медиана плотности графа по задачам. Графовая разрежённость
не означает разрежённость локального feature-space normal matrix.

## Вывод

В протестированных профилях design матрицы минимум на 99% плотные; общий sparse storage/solver не имеет достаточного zero pattern для разреженной факторизации. В manifold граф разрежён независимо от feature-space B-system. Оставить вывод условным на эти synthetic задачи.

Sparse solver можно рекомендовать только по структуре матрицы. Этот
аудит не утверждает преимущество по времени или памяти; для этого нужен
отдельный парный benchmark с теми же stopping certificates и качеством.

Подробные per-task / per-target квантили, failures, near-zero доли и
provenance находятся в `audit.json`.
