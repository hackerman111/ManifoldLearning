# Manifold ADP: проверенная область применимости

Реализация находится в `ADP/ADP_Manifold.py`. Источник формул —
`manifold-ade.tex`; прежние интерпретации сохранены в
`docs/superpowers/specs/2026-08-29-adp-manifold-design.md`.
Это supervised оценивание локального EDR по `(X, Y)`, а не восстановление
геометрии носителя `X` без отклика. `transform` возвращает координаты отдельных
локальных карт; глобальная совместимость этих координат не гарантируется.

## Что изменено

- `EXACT`: в действии CG заменены повторные `einsum(..., optimize=True)`
  на batched matrix multiplication. Оператор, правые части, штраф,
  preconditioner, допуски и распределение случайных направлений сохранены.
- `ESTIMATOR`: добавлен явный `scale_boundary="stop"`. При недостижимой
  средней массе уточняется последний допустимый function bandwidth.
  Совместимый default `"raise"` оставляет прежнее поведение.
- `trace_` дополнен минимальной/средней массой и минимальным effective sample
  size. `stop_reason_` различает `h_min`, `function_mass_boundary` и
  `manifold_mass_boundary`. Это причины остановки, а не оценки точности.

В TeX есть две разные нормировки штрафа: в лемме присутствует множитель
`W_M,l`, в финальном алгоритме — нет. Сохранена финальная формула:

```text
sum_j mass_j * w_jl * ||I_j - U_j B_l.T ell_jl||²
+ lambda_manifold * tr(B_l.T B_l (Id - I_bar_l)).
```

Здесь `mass_j=sum_i w_ij`; Kish effective sample size хранится отдельно.
`K(q)=max(1-q²,0)`, аргумент `q` уже является квадратом расстояния.
Начальные статистики вычисляются до синхронизации; manifold bandwidth
постоянен. Один шаг использует замороженные соседние проекторы. Это не
доказательство монотонного уменьшения глобального штрафного функционала:
синхронное обновление и обратная проекция relaxed `B` такого свойства не дают.

## Две разные границы

Для фиксированных `P_j, Lambda_j` положим

```text
F(h) = mean_j sum_i K(
    sum_r Lambda_jr * <P_jr, X_i - center_j>² / h²
).
```

Это максимальная средняя масса по `alpha in [0,1]`, достигаемая при
`alpha=0`. Если `F(h)<N_loc`, никакое допустимое значение анизотропии не
выполняет требование TeX. `F` не убывает по `h`.

Режим `stop` проверяет предложенный `h/a` и, если он недопустим, бисекцией
уточняет допустимую сторону скобки `[h/a,h]` до относительной ширины
`sqrt(float64 eps)`. Затем выполняется настоящий шаг обучения на найденном
масштабе и процедура завершается. Целевая масса не уменьшается; случайные
направления генерируются только для принятого масштаба.
Граница относится к геометрии, использованной для построения статистик этого
шага. После обновления проекторов она может сместиться.

Если фиксированный manifold bandwidth уже не обеспечивает его целевую массу,
процедура завершается до следующего шага с `manifold_mass_boundary`.
Если обновлённая геометрия делает всю function-скобку недопустимой, возникает
явная ошибка. Ошибки ранга, CG и нечисловые результаты не перехватываются
как успешное завершение.

Граница массы — необходимое условие доступности окрестностей, **не граница
статистической корректности**. Для восстановления также необходимы:

1. Полный численный ранг локального pilot design: этот алгоритм требует
   `n>d+1`, `d+1<N_lin<n`. Данные на точно низкоразмерном носителе могут
   нарушать это условие даже при большом `n`.
2. Ранг `m` локальных систем `U_j P_l.T`, достаточное разнообразие локальных
   градиентов для идентификации `m` направлений. Нулевой отклик не
   идентифицирует подпространство. Штраф не создаёт информацию об истине.
3. Ненулевой спектральный зазор между нужными и остальными направлениями.
   Проверка машинного ранга сама по себе не доказывает устойчивость к шуму.
4. Достаточно малые шум и изменение геометрии внутри используемых
   окрестностей. Их средняя масса ничего не говорит о каждой отдельной
   окрестности; для этого добавлены минимумы в `trace_`.

Инженерный критерий: возмущение локальной structural matrix из-за шума,
кривизны и sketch должно быть мало относительно её спектрального зазора.
Он не превращён в автоматический сертификат: без предположений о гладкости,
шуме и идентифицируемости такой гарантии из одних `(n,d)` нет.

## Измеренная область точности

Семейство `X ~ Uniform([-1,1]^d)`,
`Y = X_0 + c*X_1² + Normal(0,sigma²)`. Истинное локальное направление
пропорционально `(1, 2*c*X_1, 0, ...)` и не постоянно при `c>0`.
`n=600`, `m=1`, `J=40`, `P=15`, `N_loc=30`, `N_lin=80`,
`N_manifold=6`, `sync_steps=2`, `h_min=0.001`, `scale_boundary="stop"`.
Три seed: 7, 19, 31; независимые потоки для данных, шума и метода.

Ошибка — Frobenius-норма разности истинного и оценённого проекторов в
выбранных центрах. Критерий эксперимента задан как средняя ошибка <=0.1
и максимальная <=0.2; это практический порог, не теоретическая константа.

| c | sigma | d | Диапазон средней ошибки по seed | Прошли критерий |
|---|---|---|---|---|
| 0.03 | 0.01 | 4 | 0.0350–0.0407 | 3/3 |
| 0.03 | 0.01 | 8 | 0.0397–0.0472 | 3/3 |
| 0.03 | 0.15 | 4 | 0.0919–0.1502 | 0/3 |
| 0.3 | 0.01 | 4 | 0.2361–0.2618 | 0/3 |
| 0.3 | 0.01 | 8 | 0.3359–0.4055 | 0/3 |
| 0.3 | 0.15 | 4 | 0.2595–0.2619 | 0/3 |

Все 18 запусков численно завершились на function mass boundary, но только
6 прошли критерий восстановления. При большом шуме отдельные центры имеют
ошибку >1, несмотря на умеренную среднюю ошибку. Область между проверенными
значениями `c/sigma`, большие `d`, другие распределения и локальное `m>1`
этим экспериментом не сертифицированы. Для `m=2` отдельно проходят dense
reference и end-to-end тест восстановления постоянного подпространства.

Результаты: `smooth.json`, `curved.json`. Это небольшая воспроизводимая
эмпирическая область, а не универсальная максимальная граница метода.
Ни снижение bandwidth до предела, ни повышение числа CG-итераций не устраняют
смещение от слишком большого изменения геометрии.

## Производительность и память

Профилирование `(n,d,J,P,m)=(600,8,40,15,2)` выявило `_one_step` как
основной путь: 0.935 из 1.010 секунды под cProfile; значительная часть времени
уходила на повторный поиск порядка einsum внутри CG.

В парном контроле из 9 запусков с фиксированным `h_min=0.8` суммарный
wall-clock изменился с 1.590 до 0.836 секунды (1.90 раза).
Максимальное изменение средней ошибки — `1.39e-16`. Измеренный peak
tracemalloc остался около 5.72–5.83 MiB. Измерение времени выполнено отдельно
от tracemalloc; первая точка включает warm-up. Потоки BLAS ограничены одним.
Это результат для указанных небольших задач, не гарантия ускорения при всех
размерностях. Данные и ограничение идентификации грязного baseline сохранены
в `performance.json`.

Дополнительная парная проверка `(n,d,J,P,m)=(2000,32,100,20,1)` на трёх
seed: 5.453 против 3.239 секунды суммарно (1.68 раза), peak около
42.27–42.30 MiB в обоих вариантах. Максимальное изменение средней ошибки
`8.35e-14`; числа итераций и residual находятся в trace JSON. Этот контроль
воспроизводит прежние einsum-действия через `ReferenceManifold` в benchmark,
сохраняя прочую реализацию. Файлы: `large-reference.json` и
`large-optimized.json`. Качество на этой задаче не прошло критерий
восстановления; ускорение не выдаётся за повышение точности.

Хранятся `X(n,d)`, `U(J,P,d)`, направления `(J,P,d)`, проекторы `(J,m,d)`
и CSR graph с E рёбрами. Статистики требуют рабочих `(B,P,n)` массивов.
Новый CG kernel использует `(K,d)`, `(K,P)` и `(K,m,m)` для одной строки
графа; не создаёт `(d,d)` и `(K,m,d)` penalty intermediate.
Стоимость одной итерации CG: `O(K*P*d + K*m*d + K*m²*d)`;
стоимость слоя зависит от фактического числа CG-итераций и E.
Поиск границы делает `O(log(1/sqrt(eps)))` проходов вычисления масс;
попарные расстояния остаются chunked, нового большого cache нет.

Для `n=10000,d=1000,N_loc=15`, default `J=1334,P=15`: один `U` занимает
около 153 MiB, направления ещё столько же, `X` около 76 MiB; один
`(32,15,10000)` intermediate около 37 MiB. Часть массивов существует
одновременно, а pilot SVD может быть дорогим. Такой stress-режим не запускался;
утверждение о его практической эффективности было бы преждевременным.
CG по normal operator остаётся прежним решателем: residual certificate
проверяется, но хорошая обусловленность и малая ошибка решения не следуют
из малого residual при плохо обусловленной задаче.

## Использование и воспроизведение

```python
from ADP import ADP_Manifold

model = ADP_Manifold(
    1,
    N_loc=30,
    N_lin=80,
    N_J=40,
    N_phi=15,
    N_manifold=6,
    sync_steps=2,
    h_min=0.001,
    scale_boundary="stop",
    seed=7,
).fit(X, Y)
print(model.stop_reason_, model.bandwidth_)
print(model.trace_[-1])
```

Конфигурация соответствует эксперименту; она не является универсальным
default для произвольных данных. Через основной CLI режим включается
`--mode manifold --scale-boundary stop`. Старые экспериментальные каталоги
сохраняют прежний режим; новый benchmark включает его явно.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  uv run --no-sync python -m benchmarks.manifold_boundary \
  --boundary --curvature 0.03 --output /tmp/manifold-smooth.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  uv run --no-sync python -m benchmarks.manifold_boundary \
  --boundary --curvature 0.3 --output /tmp/manifold-curved.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  uv run --no-sync python -m benchmarks.manifold_boundary \
  --large --reference --output /tmp/manifold-large-reference.json
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  uv run --no-sync python -m benchmarks.manifold_boundary \
  --large --output /tmp/manifold-large-optimized.json
```

JSON содержит настройки, seed, версии, BLAS/thread environment, commit/dirty
state, hash numerical source, ошибки, trace, время и tracemalloc peak.
Неудачные запуски остаются в таблице. Память native allocations, не видимая
tracemalloc, не включается в заявленный peak.
