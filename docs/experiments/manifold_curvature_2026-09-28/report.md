## Математическая граница наблюдаемости

Генератор задаёт `z_k=u_k+c*u_(m+k)^2/2`, `f(x)=||z(x)||²/2`.
При `c=0` имеем `z=(u_1,...,u_m)` и
`f(x)=0.5*sum_{k=1}^m u_k²`: это обычная глобальная multi-index модель с
постоянным m-мерным EDR-подпространством. Её решает именно manifold
алгоритм с отдельным проектором в каждом центре; плоская серия проверяет
его поведение на вырожденном контрольном случае, а не способность
восстанавливать кривизну. При `c>0` отклик по-прежнему можно записать как
глобальную multi-index функцию первых `2m` координат `u`; проверяемое
локальное поле `row(Dz(x))` при этом меняется с x. Это различие существенно
для интерпретации теста.
Его точный градиент — `∇f=Dz.T @ z`. Для m=1 и `z(x) != 0` направление
`row(Dz(x))` совпадает с направлением `∇f(x)`. Около `z=0` это направление
теоретически определено гладкой структурой карты, но первый производный
сигнал стремится к нулю, поэтому оценка по шумным конечным данным неустойчива.

Для m>=2 полное `row(Dz(x))` **не идентифицируется** одним скалярным f.
Пусть `R(x)` — гладкая ортогональная матрица и `z_tilde(x)=R(x)z(x)`.
Тогда `||z_tilde(x)||=||z(x)||` для каждого x, но
`D z_tilde=R Dz+(DR)z`, и второй член меняет строковое пространство.
Например, при `z=(x1,x2)`, повороте на угол `κx3` и точке `(1,0,0)`
исходное пространство есть `span(e1,e2)`, а новое —
`span(e1,e2+κe3)`. Оба объясняют точно те же наблюдения. Для m=3
добавляется неизменная третья координата. Поэтому на искривлённых m=2/3
`row(Dz)` остаётся **описательной** ошибкой генератора; проверяемая величина —
синус угла между наблюдаемым `∇f` и оценённым m-мерным пространством.
Это необходимое условие корректности, не доказательство восстановления всей
касательной плоскости. Полный базис плоского контроля проверяется в
[`repair.md`](../manifold_generalization_2026-09-28/repair.md).

## Механизм ошибки исходного алгоритма

В точке `l` инициализация берёт top-m правых сингулярных векторов матрицы
взвешенных градиентов соседних центров. Она оценивает eigenspace смеси
`S_l=Σ_j mass_j*w_lj*∇f(x_j)∇f(x_j).T`. При c>0 градиенты соседей лежат
в **разных** `row(Dz(x_j))`; матрица смеси может иметь ранг до 2m и её
top-m eigenspace не обязан совпадать с `row(Dz(x_l))`. Это смещение есть
даже при точных градиентах. Сужение графа уменьшает смешивание, но требует
достаточной локальной массы и ранга для каждого центра. Прежний режим
`relative` дополнительно расширяет ядро вдоль слабых собственных направлений;
`unit` устраняет этот плоский спектральный механизм, но не геометрическую
смесь. `scale_boundary="stop"` даёт завершить численно допустимый fit, но
не восстанавливает потерянную геометрию.

Асимптотика поясняет, почему для m>1 простое сужение графа не является
универсальным решением. При `g=∇f`, `g(x+δ)=g(x)+H_f(x)δ+O(||δ||²)`.
После проекции на дополнение к `g(x)` ведущая ковариация соседних
градиентов пропорциональна
`h² P_perp H_f Σ H_f.T P_perp`. Для данного генератора
`H_f=Dz.T Dz+Σ_k z_k H(z_k)`. Второй член при c>0 и `z_k!=0`
имеет компоненты вне `row(Dz)`. Они входят в ту же степень `h²`, что и
сигнал о дополнительных m−1 направлениях. Первый сильный вектор при
`g!=0` может сходиться к направлению `g`, но оставшиеся векторы локальной
PCA градиентов не обязаны сходиться к `row(Dz)`. В ADP-статистике каждого
центра при малом bandwidth также остаётся одна скалярная первая производная;
rank-m задача вынуждена брать дополнительную информацию из соседей.

|---|---:|---:|---:|---:|
| m=1, c=.35 | .551 | .268 | .297 | .651 |
| m=1, c=.8 | .518 | .588 | .525 | .886 |
| m=2, c=.35 | .641 | .261 | .307 | .629 |

Числа для точных градиентов получены только в контрфактической
инициализации: truth не передавался в настоящий fit. В broad/unit завершены
60/60 fits без численных ошибок, но **0/60** проходят all-center RMS и max
`<=.2` даже по более слабому критерию включения наблюдаемого градиента.
С точными градиентами и исходным графом также 0/60 проходят этот gate.
Максимальный сертифицированный линейный residual в завершённых broad fits
`9.999e-7` при `cg_tol=1e-6`, значит провал геометрии не объясняется
неудачным CG. Все 60 остановились на function-mass boundary.

В local/unit завершены 39/60 fits; остальные 21 прерваны проверкой ранга.
Среди всех 60 попыток также 0 проходят observable-gradient gate. Для m=1
обычный linear pilot и прежний 60-соседний quadratic pilot имеют медианы
худшего по центрам синуса около .996–.999 на c=.35/.8: простая замена
локального пилота не устраняет наихудшие точки. Для m=1 по десяти broad
попыткам на каждом c медиана минимального точного `||∇f||` среди центров
составляет .0078 при c=.35 и .0102 при c=.8; минимальное значение при
c=.8 — `3.59e-5`. Такие центры усиливают ошибку направления.

Это ограничение относится к проверенной умеренной/сильной кривизне и
конечному протоколу, а не к любой ненулевой кривизне: существующий
`test_varying_direction_learns_at_mass_boundary` проходит на более мягкой
геометрии при `d=4`. Без количественного ограничения гладкости нельзя
гарантировать даже градиент на всех центрах при конечной выборке: гладкую
локальную добавку можно занулить во всех наблюдаемых точках, но оставить
произвольную производную в одном центре. Для uniform-гарантии нужны класс
гладкости, достаточная локальная плотность и контроль малого `||∇f||`.

Отдельно публичный nearest-chart query имеет дискретизационный предел:
медиана максимальной ошибки **точного** ближайшего center chart в broad/unit
от .664 до .988 по шести `(m,c)` профилям. Поэтому raw query-to-true-query
ошибка не может быть обязательным gate для этих данных; ошибка оценки того
же chart должна считаться отдельно.

## Проверенный вариант и решение

После отрицательного reference gate проверен один отдельный структурный
вариант: top-2m подпространство выборочного Gaussian Stein-момента
`E[Y(XX.T−I)]`, затем степень-4 полином в этих координатах с ridge,
выбранным трёхкратной CV только по отклику. В population для заданного
генератора этот момент пропорционален диагонали с m значениями `1` и m
значениями `3c²/2` в координатах `u_1..u_2m`, поэтому гипотеза
математически обоснована при Gaussian X и c>0. Экспериментальная реализация
и конечные разности градиента — [`polynomial_probe.py`](polynomial_probe.py),
12 preflight строк — [`polynomial_preflight/runs.jsonl`](polynomial_preflight/runs.jsonl).
Оба source hash из manifest совпадают с live файлами.

На seed 81000 для m=1/2/3, c=.35/.8, шума 0/.1: 12/12 вычислений
завершились, **0/12** прошли all-center gradient RMS/max `<=.2`.
Наибольший синус угла между оценённым global active subspace и истинным
лежал в диапазоне .321–.583. Медиана времени 0.015 s, накопительный
RSS 79.5 MiB. Finite-sample ошибка глобального подпространства уже велика;
сохранение этого варианта как production estimator было бы необоснованным.
Положительную untouched curved validation не запускали после провала
preflight.

Итак, тюнинг spectrum, sync-шагов, исходного локального пилота и этот
структурный pilot не дают стабильного восстановления на проверенной
кривизне. Для полного rank-m поля при m=2/3 нужна дополнительная
идентифицирующая информация о карте или другой отклик; пользователь
сохранил скалярный отклик, поэтому такая подмена задачи не сделана.
Для стабильной оценки наблюдаемого градиента при m=1/2/3 понадобятся
явные ограничения гладкости/сигнала и отдельная выборка с достаточной
локальной плотностью; текущий протокол их не обеспечивает.
