# C2: одно правило до full-fit результатов

Фиксация 2026-09-25, после C1 и до C3. Все величины ниже вычисляются только
на обучающих `X,Y` и случайном пуле из `J₀=500` центров. Истинный basis,
`trace_score`, validation labels и результат ADP fit недоступны.

## Pilot и допустимость

Использовать C1 `h_lin`, `h_outer`, веса `w_lin`, `w_outer`. Центр допустим,
если raw weighted-centered design при `h_lin` имеет rank `d`, а при
`h_outer` support и `n_eff` не меньше `m+2=4`. Rank здесь диагностический,
без ridge. Пул, не имеющий допустимого J из сетки ниже, отвергается.

Пусть `g_j = Cov_{w_lin,j}(X,Y) = E_w[(X-E_w X)(Y-E_w Y)]`.
Это кросс-ковариация, а не точный local ridge gradient: без почти сферической
локальной ковариации направление может быть смещено. Пилотный `B₀` из двух
старших правых сингулярных векторов строк `sqrt(mass_lin,j) g_j` на полном
случайном пуле. Если второй сингулярный компонент численно неотличим от нуля,
отбор не определён. Положить

`v_j = sqrt(n_eff_outer,j/N_loc) B₀ᵀg_j / median_k ||B₀ᵀg_k||`.

Знаменатель берётся по допустимым центрам; если он нулевой, отбор не
определён. Эта нормировка фиксирует масштаб score в каждом наборе обучения.
Ротация пилотного basis внутри его подпространства не меняет score.

## Greedy и остановка

Для выбранного набора S определить `A_S = I_m + Σ_{j∈S}v_jv_jᵀ`.
При добавлении j точный прирост logdet равен
`log(1+v_jᵀ A_S⁻¹ v_j)` (matrix determinant lemma). Пока доля обучающих
строк, имеющих положительный `w_outer` хотя бы от одного выбранного центра,
ниже `0.99`, брать центр с наибольшим приростом **числа** покрытых строк;
при равенстве — наибольший logdet-прирост. После достижения `0.99` брать
наибольший logdet-прирост. Финальный tie — меньший исходный ID строки.
Это правило использует support и D-optimal surrogate, но D-optimality
кросс-ковариаций не доказывает recovery EDR.

Снимать вложенные префиксы greedy длиной `125,250,375,500` (если хватает
допустимых центров). Для префикса длины k вычислить

`L_k = logdet(I_m + (J₀/k) Σ_selected v_jv_jᵀ)`;
`L_ref = logdet(I_m + (J₀/M) Σ_feasible v_jv_jᵀ)`, где M — число
допустимых центров. Нужны `coverage >=0.99` и `L_k/L_ref >=0.95`.
Выбирать **минимальное** k из сетки, удовлетворяющее обоим условиям.
Если `L_ref<=1e-12`, M недостаточно, или нет префикса `k<J₀`, кандидат
для этого seed отсутствует; random J₀ остаётся baseline. Если такое
случится хотя бы на одном из 20 selection seed, C2 не даёт кандидата для
обязательного C4-условия `J<J₀` на каждом seed; ветку остановить до C3.

Сеточные пороги и формулы нельзя менять после просмотра C3 fits. В C2
проверять детерминизм, точный logdet и greedy на малом dense reference,
бюджет pilot+selection и все 20 seed. Расход памяти: `O(J₀n+J₀d+J₀²)`
в эксперименте, без `(J,n,d)`, `(JP,md)`, `d×d` information matrix или
использования неизвестного projector. Полный wall/RSS pilot+selection
добавляется к кандидату при сравнении C3/C4.
