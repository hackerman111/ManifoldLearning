# S3 — изолированный guarded reduced L-BFGS prototype

После [proof gate](s2_derivation.md) добавлен экспериментальный `experiments.reduced_lbfgs.solve`, возвращающий прежний `HPAOResult` с `(m,d)` basis и локальными коэффициентами. Он минимизирует текущий усечённый reduced objective, использует горизонтальный gradient, polar retraction, ограниченную историю L-BFGS, descent safeguard и Armijo. При выходе из rank/error области или исчерпании line search явно сообщает ошибку; `converged=True` требует прежнего общего сертификата на двух подряд принятых шагах. `lambda_prox` валидируется для совместимости, но не входит в statistical objective. Default и публичный estimator не менялись.

Малый независимый SVD reference — `experiments.multi_solver_derivation.evaluate_reduced`; общий внешний certificate — `experiments.multi_solver_certificate.evaluate`. Проверки:

```bash
OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m pytest -q -p no:cacheprovider \
  tests/test_lsmr.py tests/test_multi_solver_certificate.py \
  tests/test_multi_solver_derivation.py tests/test_reduced_lbfgs.py
```

Результат: 18 passed. Покрыты m=2/5, полный и структурно пониженный rank, zero U, независимый objective/stationarity, касательные finite differences, rotation invariance результата, монотонность, ортогональность, invalid/zero mass, слишком маленький retained singular, failure line search и запрет фиктивного двухшагового сертификата. Ruff check/format проходит для всех изменённых Python-файлов.

Пробный запуск **только пяти шагов** на двух frozen задачах seed1000 outer0 подтвердил конечность и отсутствие rank-guard rejects: d10 objective `94.6267→92.9323`, d100 `385.7444→335.9026`; независимый evaluator подтвердил конечные значения. Оба корректно вернули `max_steps`, так как пяти шагов для сертификата недостаточно. Это проверка исполнения, не оценка скорости или качества.

Synthetic stress с rank-one U и произвольным I первоначально был отвергнут начальным error guard: отброшенная положительная сингулярная компонента могла объяснить значимую часть I. Для проверки допустимой области использован I из span(U); отдельный контрпример сохранён в `test_multi_solver_derivation.py`. Guard выполняет предусмотренную proof-ом границу, поэтому это не ослабление условия ради теста.

Статус: S3 принят как прототип. Следующий этап сравнивает время до общего certificate на тех же 12 frozen задачах, учитывая каждый timeout и failure. До этого сравнения solver не добавляется в CLI и полные fits не запускаются.
