# Масштабирование `N_phi`, `N_loc` и `N_J`

## Цель и классификация

Сетки проверяют эффективные значения трёх параметров в зависимости от `(n, d)`
отдельно для single-index и multi-index (`m=2`). Изменение каждого параметра
меняет конечный estimator, поэтому все шесть серий имеют классификацию
`ESTIMATOR`; численное ядро и solver в них одинаковы.

Эффективным считается минимальный по медианному времени параметр на границе
Парето, который одновременно:

- не увеличивает частоту `numerical_failure` и `nonconverged`;
- для single-index сохраняет `cosine_abs >= 0.9`;
- для multi-index сохраняет эквивалентную границу `trace_score >= 0.95`, где
  `trace_score = trace(P_hat P_true) / m = mean(cos(theta_j)^2)` при `m=2`;
- по качеству отличается от лучшего уровня не более чем на `0.01` для SI и
  `0.02` для MI.

Качество, сходимость, время и память рассматриваются раздельно. Технический
`local_mass_limit` сам по себе не означает ни успеха, ни плохого качества.

## Основания для гипотез

Прошлые серии по одному `(n, d)` недостаточны для общей зависимости. Тем не
менее они задают диапазоны:

- в диагностике multi-index случай `N_phi=m=10` почти интерполировал локальную
  систему и практически не обновлял базис; `N_phi=15,20,30` уже давали заметное
  обновление;
- в `mi-focus-nphi` при `n=1000`, `d=25`, `m=2` медианная ошибка проектора была
  наименьшей около `N_phi=28--32`, но все три запуска каждого уровня оставались
  `nonconverged`, поэтому это пилотная, а не итоговая оценка;
- старые `si-centers` показывают почти линейный рост времени и памяти с `N_J`,
  но нестабильное качество и отсутствие формальной сходимости не позволяют
  выбрать уровень напрямую;
- старые `si-nloc` также смешивают хорошее качество с большим числом
  `numerical_failure`, поэтому значения `7--20` расширены до `45`.

## Проверяемые гипотезы

### H_phi

После условия `N_phi > m` число направлений определяет точность случайного
эскиза, а не число наблюдений. Поэтому оптимум должен слабо зависеть от `n`,
умеренно расти с `d` и выйти на плато около `20--30`. Для MI проверяется также
нижняя граница `N_phi=3` при `m=2`. Стоимость ожидается возрастающей по
`N_phi`, даже после насыщения качества.

### H_loc

При фиксированном `N_loc` рост `n` уменьшает геометрический радиус окрестности,
но не дисперсию локальной статистики. Поэтому эффективный `N_loc` должен расти
с `n` суб-линейно. После структурной адаптации зависимость от ambient `d`
ожидается слабее зависимости от `n`: слишком малый `N_loc` даёт нестабильные
окрестности, слишком большой увеличивает локальное смещение.

### H_J

Центры покрывают выборку локальными окрестностями порядка `N_loc`, поэтому
естественный безразмерный параметр — `c = N_J*N_loc/n`. Гипотеза:
`N_J = c*n/N_loc` с почти постоянным `c`; полезное плато ожидается при
`c=4--8`, после чего время и память продолжают расти почти линейно.

## Сетки и фиксированные условия

- полный факторный дизайн: `n={500,1000,2000}`, `d={10,25,50}`;
- пять повторов на грубую точку, одинаковые данные и seed bundle внутри каждой
  пары `(n,d)`;
- `N_phi={5,10,20,30,40,60}` для SI и `{3,5,10,20,30,40}` для MI;
- `N_loc={7,10,15,20,30,45}`;
- `N_J=ceil(c*n/N_loc)`, `c={1,2,4,8,12}`;
- при варьировании одного параметра остальные фиксированы:
  `N_loc=15`, `N_phi=20`, `N_J=ceil(n/5)`;
- независимые Gaussian-признаки, шум `0.2`, `sin(x)` для SI,
  additive-link для MI, `select_step=best`;
- SI использует local initialization и localized directions, MI — pilot
  initialization и isotropic directions.

Пять повторов предназначены для screening. Финальную зависимость следует
подтвердить минимум на 25 seed'ах только после сужения диапазона; иначе полная
сетка потребует 1530 fit'ов.

## Запуск

Быстрая проверка шести серий каталога:

```bash
UV_CACHE_DIR=/tmp/adp-uv-cache MPLCONFIGDIR=/tmp/adp-matplotlib \
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
uv run --no-sync python -m ADP.cli.experiment \
  --experiment parameter-scaling --profile smoke --no-plots
```

Полный screening:

```bash
UV_CACHE_DIR=/tmp/adp-uv-cache MPLCONFIGDIR=/tmp/adp-matplotlib \
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
uv run --no-sync python -m ADP.cli.experiment \
  --experiment parameter-scaling --profile full --runs 5
```

Группы `parameter-scaling-si`, `parameter-scaling-mi` и отдельные селекторы
`scale-{si,mi}-{nphi,nloc,nj}` позволяют запускать серии независимо.
Результаты сохраняют requested/effective config, seed bundle, quality,
сходимость, время, traced peak memory и фазовые таблицы по `(d,n/d)`.

## Уточняющие сетки по `n` и `d`

Группа `nd-detail` развивает screening двумя сериями с десятью повторами:

- `mi-boundary-nd`: фиксирует estimator и перебирает
  `n={400,600,800,1000,1400,1800,2400}` и
  `d={10,15,20,25,30,35,40,50,60}`. Это 63 точки для оценки частоты
  `trace_score >= 0.95`, `nonconverged` и `numerical_failure` отдельно;
- `si-nloc-nd`: парно сравнивает `N_loc={10,15,20,25,30,40,50}` на одних
  данных для каждой пары `n={400,700,1000,1500,2200}` и
  `d={10,20,30,40,50,60}`. Это 210 точек для разделения выигрыша в качестве,
  сходимости и времени.

Изменение `(n,d)` в первой серии относится к дизайну данных, estimator там
фиксирован. Изменение `N_loc` во второй серии имеет классификацию `ESTIMATOR`.
Полная группа содержит 2730 fit'ов; серии можно запускать независимо.

```bash
UV_CACHE_DIR=/tmp/adp-uv-cache MPLCONFIGDIR=/tmp/adp-matplotlib \
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
uv run --no-sync python -m ADP.cli.experiment \
  --experiment nd-detail --profile full --runs 10
```
