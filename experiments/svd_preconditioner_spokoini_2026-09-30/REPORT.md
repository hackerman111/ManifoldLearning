# Предобусловливатель на прежней 25-секундной задаче

## Результат

На прежней задаче Spokoiny (`n=800`, `d=50`, `m=2`, `N_J=800`) запуск с
`precondition_v=True` не ускорил fit. Медиана парных отношений времени
`вкл./выкл.` равна **1.0022**: на этих трёх seed включённый флаг дал в среднем
по парному отношению около **0.22% больше времени**. Проекторная ошибка и
число внешних шагов в каждой паре совпали.

Причина подтверждена диагностикой: `d=50` меньше порога прямого решателя
`direct_max_dimension=128`. Во всех шести запусках LSMR-итераций было ноль;
выполнено 1977, 2407 и 2238 прямых v-решений для seeds 0, 1 и 2
соответственно. Предобусловливание применяется только к итеративным
положительно-регуляризованным v-задачам, поэтому на данном полном fit его
численный путь не вызывался. Поле `updates_with_flag_enabled` показывает,
что настройка передана в диагностику outer-шага; оно не считает вызовы
предобусловливателя.

| Seed | Без, с | `precondition_v=True`, с | Изменение времени | Ошибка проектора, обе версии |
|---:|---:|---:|---:|---:|
| 0 | 25.739 | 25.796 | +0.22% | 0.1183134 |
| 1 | 25.553 | 25.062 | −1.92% | 0.0898671 |
| 2 | 25.689 | 26.005 | +1.23% | 0.0986986 |
| Медиана парных отношений | — | — | **+0.22%** | разница 0 во всех парах |

Оба варианта завершили 162 внешних шага на каждом seed. Парное изменение
времени меньше наблюдаемого разброса между seed; устойчивого ускорения для
этой задачи не видно. Медианный process peak RSS составил 100.81 MiB без
флага и 103.90 MiB с флагом. Это `ru_maxrss` отдельного свежего процесса
вместе с импортами и данными, не изолированная оценка памяти солвера; кэш
предобусловливателя равен нулю.

## Воспроизводимость

Использован прежний случай из
`experiments/svd_vs_hybrid_spokoini_dhigh_30s_untraced_2026-09-28`: Spokoiny,
`N_loc=10`, `N_lin=100`, `N_phi=10`, `a=exp(1/100)`, `h_min=1`, полное внешнее
расписание, `lambda_penalty=0.05`, матричная цель SVD, rank=1. Сохранены
генератор данных и initialization seed-bundle; у каждой пары один и тот же
seed. Каждый fit запущен в новом процессе с одним потоком BLAS, без
`tracemalloc`; порядок в паре чередовался. Таймер охватывал fit, как в
исходном бенчмарке.

Ранее сохранённые времена этого workload были 24.919, 25.099 и 25.199 с.
Нынешние абсолютные времена немного отличаются, поэтому вывод о влиянии
флага основан на новых парных запусках, а прежние числа служат контекстом.

Шесть полных строк и конфигурация находятся в `runs.jsonl` и `manifest.json`;
`summary.json` построен командой ниже. Первую попытку запуска, где ошибка
аргументов остановила worker до fit, оставил отдельно в
`harness_failures.jsonl`; в результатах измерений её нет.

```sh
rtk proxy env OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 UV_CACHE_DIR=/tmp/adp-uv-cache PYTHONPATH=. uv run --no-sync python experiments/svd_preconditioner_spokoini_2026-09-30/benchmark.py
rtk proxy env UV_CACHE_DIR=/tmp/adp-uv-cache uv run --no-sync python experiments/svd_preconditioner_spokoini_2026-09-30/analyze.py
```

Вывод применим к этой задаче с `d=50` и её прямому пути. Он не измеряет
предобусловливатель в LSMR-режиме для `d>128`.
