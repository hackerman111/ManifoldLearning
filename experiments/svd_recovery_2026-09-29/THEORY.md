# Полный шаг вместо усечения B

Статус: математический вывод проверен независимым агентом; качество полного
ADP требует отдельных экспериментов. Исходные материалы пользователя:
`SVD/problem.md`, `SVD/SVD.tex`, `SVD/SVD_form.tex`. Последний документ требует
pure rank(B) постановку; предлагаемая здесь **явная новая ESTIMATOR-ветка**
снимает это ограничение, а не выдает другую задачу за реализацию той теории.

Пусть A(X)_j=sqrt(N_j) U_j X^T g_j, b=sqrt(N) I-A(P).
Тогда F(P+Delta)=||A Delta-b||²+lambda||Delta||². При lambda>0
K=A* A+lambda I положительно определен. LSMR с damp=sqrt(lambda)
решает соответствующую augmented LS без формирования K. Старый
`LSMR._linear_operator` уже содержит нужные forward/adjoint.

Поскольку Delta=0 допустима, F(B*)<=F(P); обязательного нижнего порога
lambda(m-r) больше нет. Полный row rank B* из этого не следует: его проверяем
отдельно перед извлечением базиса. Вырождение вызывает явную ошибку.

Для невязки r=A*(A Delta-b)+lambda Delta (половина градиента F):

- ||Bhat-B*||_F <= ||r||_F/lambda;
- F(Bhat)-F(B*) = <r,K^{-1}r> <= ||r||²/lambda.

Относительный сертификат ||r||/max(1,||A*b||) не является относительной
ошибкой решения. Даже малый сертификат не гарантирует спуск от почти
оптимального P: отдельно проверяем F(Bhat)<=F(P)+roundoff.

Если sigma=sigma_m(B*)>0 и e=||Bhat-B*||_2<sigma, то Bhat имеет полный
row rank. Для проекторов строк ||Pi_hat-Pi_*||_2<=e/sigma и
||Pi_hat-Pi_*||_F<=sqrt(2)||Bhat-B*||_F/sigma. Это сравнение с fixed-g
оптимумом, а не с истинным EDR. При lambda=0 нужны отдельные условия
инъективности; численный минимально-нормовый шаг возможен, но эти границы
не заявляются.

Thin SVD Bhat=T Q дает ортонормированный Q и сохраняет предсказания при
замене коэффициентов g на g T. Точный local LS refit может только уменьшить
data loss. Численное отсечение малых singular values в существующем refit
имеет собственный roundoff-domain. Proximal F после ортонормирования уже
другая величина; его спуск для Q не утверждается.

Дополнительная память оператора O(Jd+md+Jp), поверх входящего U=(J,p,d).
Нет матриц d*d или md*md, нет тензора (J,p,m,d). При J=10000,d=1000
основной временный (J,d) имеет размер 80 MB в float64; сам supplied U
не становится меньше. Один глобальный Krylov solve заменяет до
r*inner_maxiter отдельных v-solve и повторных rank-one factor updates.
Выигрыш во времени должен измеряться, поскольку глобальное число
неизвестных увеличивается до md.

Независимый аудит: подтвердил взвешенный adjoint в LSMR.py:504-545,
границы и память; потребовал явной проверки спуска, rank и раздельного
описания fixed-g objective, data loss после refit и adaptive recovery.
