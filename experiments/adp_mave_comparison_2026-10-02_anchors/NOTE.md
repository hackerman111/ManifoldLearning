# First response-anchor run

This full three-seed run uses the same five-anchor dMAVE discretization and
method settings as the final report. It is retained as the first complete
measurement. The final artifact at
`experiments/adp_mave_comparison_2026-10-02_anchors_final/` repeats all 12 fits
and adds expanded build and method configuration to `protocol.json`.

Treat the two runs as repeated measurements of the same protocol, not as
independent seeds to pool.
