# Plan: ADP vs MAVE, dMAVE, and rMAVE benchmark

- **Task ID:** `adp-vs-mave-dmave-rmave-2026-10-02`
- **Status:** done
- **Goal:** add a reproducible benchmark comparing this repository's multi-index ADP fit with R MAVE, a density-response dMAVE discretization, and a benchmark-only rMAVE refinement on identical synthetic data. Compare subspace recovery quality and fit time.
- **Non-goals:** change the production ADP estimator/API; claim equivalence between distinct estimators; present dMAVE or rMAVE as exported `MAVE` package methods.
- **Known evidence:** the local R 4.6.1 / MAVE 1.3.12 package exposes `mave.compute` methods `CSOPG`, `CSMAVE`, `MEANOPG`, `MEANMAVE`, `KSIR`, but no methods named dMAVE/rMAVE. It accepts matrix response. `ADP_multi_index(...).fit(X,y)` returns `basis_` with shape `(d,m)`. Use the principal-angle/subspace metric because basis columns are non-identifiable up to rotation.
- **Method definitions:** MAVE uses the package's `CSMAVE` method. dMAVE discretizes the density-response integral at five fixed response quantiles: for each anchor `t`, fit package `CSMAVE` to `K_h(y-t)`, then average projectors and take the leading `m` eigenvectors. rMAVE is an isolated R refinement initialized by package `CSOPG`, with projected-space Gaussian weights and alternating local/global weighted least squares. Label dMAVE's anchor quadrature and rMAVE's custom implementation explicitly in artifacts.
- **Mathematical invariants:** all methods receive the same seeded `(X,y)`; truth and estimates are compared as `m`-dimensional subspaces using projector overlap `trace(P_hat P_true)/m` and projector distance `||P_hat-P_true||_F/sqrt(2m)`; higher overlap and lower distance are better. Preserve the configured response model and report failed fits rather than dropping them.
- **Timing boundary:** report fit time separately from process startup/package loading; include each method's initialization, all dMAVE anchor fits, response-kernel construction, and rMAVE refinement in fit time. Pin BLAS/OpenMP threads to one. Include dimensions, seeds, method settings, package/runtime versions, and per-fit errors in raw output.
- **Read set:** `agent-notes/WORKFLOW.md`, `agent-notes/contracts/research.md`, `agent-notes/contracts/numerics.md`, `agent-notes/ADP/multi-index.md`, `ADP/core/multi/ADP_multi_index.py`, `ADP/core/ADP_Config.py`, and the benchmark files added for this task.

- **Limit:** this is a small synthetic comparison of distinct estimators; it does not establish general superiority. dMAVE is a five-anchor discretization, and rMAVE is a benchmark-only implementation because installed MAVE exposes neither named method.
- **Stop conditions:** stop and report if the installed R package/API differs from the inspected version, if any method cannot produce a rank-`m` basis, or if paired methods are not evaluated on identical data. Do not claim scientific superiority from the default small synthetic suite alone.
