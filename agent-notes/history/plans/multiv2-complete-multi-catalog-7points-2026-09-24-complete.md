# PLAN — отдельный каталог multi v2 с сетками от 7 точек

## Цель

Добавить `python -m experiments.multiv2` со всеми сценариями из `multi.catalog()` и минимум семью различными точками в каждой сетке. Обзорный профиль v2 должен сохранять полную сетку.

## Вне задачи

- Менять estimator, численный код, критерии качества и исходный `experiments.multi`.
- Запускать реальные fits; достаточно dry-run всего v2-каталога.

## Известные свидетельства

- `experiments.multi --list` содержит 38 сценариев; восемь имели только две точки (`mi-link`, `mi-training`, `mi-init`, `mi-tensor`, `mi-direction-law`, `mi-direction-refresh`, `mi-focus-tensor`, `mi-focus-init`). Остальные уже имели минимум семь.
- Два типа link можно исследовать по сетке `link × link_scale` из 8 сочетаний. Бинарные варианты обучающей выборки, инициализации, тензора и закона направлений сравниваются на четырёх уровнях шума, также давая 8 точек.
- В исходном multi overview числовые оси сокращаются до трёх уровней; для v2 нужна полная сетка, как в manifold.

## Инварианты

- Точки из оригинального каталога сохраняются; расширяются только восемь двухточечных серий.
- Сохраняются mode `multi`, метрики, quality threshold, seed/run protocol и solver.
- Варианты имеют отдельные селекторы и CLI, исходный `multi` не меняет состав или профиль.
