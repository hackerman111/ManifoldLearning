# Multi-index ADP

## Модель и объект оценки

`Y_i = f(P X_i)+ε_i`, где `P ∈ R^(m×d)`, `P Pᵀ=I_m`, `m≪d`. Искомый объект — `m`-мерное EDR-подпространство `range(Pᵀ)`. Базис внутри него не идентифицируется: строки можно поворачивать или менять знаком. Сравнивать следует проекторы `PᵀP` или principal angles, не элементы матриц `P`.

В одном месте `multiindex.tex` `[X-MI-PRE]` записывает `P x = Σ_m (β_mᵀx)β_m`, что является вектором в `R^d`, хотя там же `P` объявлена отображением в `R^m`. Для последующих формул согласованное чтение — строки `P` являются ортонормированным базисом, reduced coordinates равны `P x ∈ R^m`, а градиент по исходным признакам равен `Pᵀg_j`.

## Направленные локальные моменты

Для каждого центра `x_j` и веса `w_ij=K(||T(X_i−x_j)||²)` вычислить

```text
N_j    = Σ_i w_ij
Xbar_j = N_j⁻¹ Σ_i w_ij X_i
I_j,s  = N_j⁻¹ Σ_i w_ij Y_i <X_i−Xbar_j, s>
u_j,s  = N_j⁻¹ Σ_i w_ij (X_i−Xbar_j)<X_i−Xbar_j, s>
U_j    = rows(u_j,sᵀ) ∈ R^(P×d),  I_j ∈ R^P.
```

Taylor-разложение `f(PX_i)≈c_j+g_jᵀP(X_i−x_j)` и взвешенное центрирование дают `I_j≈U_jPᵀg_j`; константа `c_j` сокращается. Поэтому ADP не подгоняет полную локальную поверхность ответа, а связывает локальные directional derivatives с одним общим подпространством.

Рукописная цель с массой:

```text
min_{P Pᵀ=I, {g_j}}  Σ_j N_j ||I_j − U_j Pᵀg_j||².
```

## Один AO-шаг

Вход: `I_j`, `U_j`, `N_j`, `P_init`, `λ` `[X-MI-AO]`. Источник расслабляет `P` до `B ∈ R^(m×d)`, а после шага извлекает ортонормированный базис SVD/eigendecomposition.

1. При фиксированном `P_init`, независимо по каждому центру, решить

   ```text
   ghat_j = argmin_g ||I_j − U_j P_initᵀ g||².
   ```

   Это обычный LS размера `P×m`; скаляр `N_j` не меняет локальный minimizer. В TeX `[X-MI-AO]` не закреплены solver и защита от rank deficiency.

2. При фиксированных `ghat_j` решить указанную в источнике общую квадратичную задачу

   ```text
   Bhat = argmin_B Σ_j N_j ||I_j − U_j Bᵀ ghat_j||²
                         + λ ||B − P_init||_F².
   ```

   `multiindex.tex` `[X-MI-AO]` прямо оставляет пометку «provide a closed form solution». Не считать формулу обновления реализованной или однозначно специфицированной. Из аргумента следует линейная система по `vec(B)`; её нормальные уравнения содержат сумму операторов вида `N_j (ghat_j ghat_jᵀ) B (U_jᵀU_j)`. Для устойчивой реализации нужно выбрать solver отдельно, не формировать огромную матрицу Kronecker без оценки размера.

3. Сформировать структурную матрицу

   ```text
   J = Bhatᵀ (Σ_j N_j ghat_j ghat_jᵀ) Bhat ∈ R^(d×d),  rank(J)≤m.
   ```

   Взять `m` главных направлений как строки `P_out`, сохранить диагональ спектра `Λ` `[X-MI-AO]`. Источник обычно нормирует `Λ`, чтобы `||Λ||=1`; до использования в `T` нужно сверить, применяется ли нормировка (`λ_1=1`) или сохраняется сырой масштаб.

Повторять AO `k_max` раз, передавая `P_out` как `P_init` `[X-MI-PROC]`. Штраф и последующая ортогонализация образуют relaxed/block-coordinate procedure; глобальная сходимость в источниках не доказана.

## Инициализация и structure adaptation

1. Оценить полные градиенты `∇hat g(x_j)` локальной affine-регрессией по `X_i−x_j`; собрать `J_init=Σ_j ∇hat g_j∇hat g_jᵀ`, взять `m` главных собственных векторов `[X-MI-PROC]`.
2. Положить начальные веса изотропными, `T_0=h_0⁻¹I`; `h_0` определяется требованием к средней по центрам массе `[X-MI-PRE]`, `[X-MI-PROC]`.
3. На outer-итерации пересчитать локальные моменты, решить AO, обновить `P_k,Λ_k` `[X-MI-MAIN]`.
4. Если остановка по `h_min` не наступила, уменьшить `h_k=h_{k−1}/a` и обновить анизотропный локализатор из `P_{k−1},Λ_{k−1}`. В исходниках `[X-MI-STRUCT]`, `[X-MI-MAIN]` приведены два неэквивалентных варианта:

   ```text
   T² = h⁻² [ α² I + PᵀΛP ]
   T² = h⁻² [ α² (I−PᵀP) + PᵀΛP ].
   ```

   Первый добавляет isotropic ridge во всех направлениях; второй — только в дополнении к EDR. TeX называет второй default в одном комментарии, но формулировка выбора меняется между разделами. `α` подбирается по целевой средней массе. Сэмплирование направлений в теоретическом абзаце идёт из `N(0,T²)` `[X-MI-STRUCT]`, а в main procedure `multiindex.tex` — из `N(0,I)` `[X-MI-MAIN]`.

Один из текстов задаёт уменьшение `h` на `a=2^(1/m)` `[X-MI-PROC]`; таблицы также предлагают соседние значения. Это настройка рукописи, а не доказанная универсальная скорость.

## Метрики и ограничения

- Для истинного подпространства `P_*` в `multiindex.tex` предложена ошибка `||P(I−P_*ᵀP_*)||_F²`, инвариантная к выбору базиса `[X-MI-QUALITY]`; используйте её лишь если известна truth в симуляции.
- Data fit через `Y_{i(j)}−S_j` — proxy качества/остановки, не непосредственная ошибка подпространства `[X-MI-DATA]`.
- Условие на массу усредняется по центрам и не гарантирует, что каждая локальная задача имеет данные или полный ранг.
- Размер `J` матрицы `U_j` равен `P×d`; не путайте число индексов `m` с числом случайных направлений `P`.
- Локальные `g_j`, глобальный `B`, спектральная нормировка `Λ`, штраф `λ` и повторная ортогонализация — части одной спецификации. Изменение одной из них меняет фактическую задачу.

## Отличия двух изложений

- `multiindex.tex` ADP нормирует `I_j,U_j` делением на `N_j`, затем взвешивает квадратичную ошибку на `N_j` `[X-MI-PRE]`, `[X-MI-AO]`.
- Разделы до ADP в `manifold.tex` описывают более общий multi-index fit с локальными intercept `f0_j`, `S_j` и auxiliary-observables `[M-MI-PRE]`; не заменяйте им центрированную ADP-цель.
- В общем multi-index разделе `manifold.tex` есть начальное `T_0=h_0⁻²I` `[M-MI-IMPL]`, расходящееся с весом `K(||Δx||²/h_0²)` и `T_0=h_0⁻¹I` в `multiindex.tex` `[X-MI-STRUCT]`.
- Исправление источника: формула `fcl_j U_j β` находится не в конце `multiindex.tex`, а в ADP multi-index outer procedure в `manifold.tex` `[M-ADP-MI-MAIN]`; она выглядит как оставшийся single-index фрагмент. В `multiindex.tex` main procedure `[X-MI-MAIN]` записана multi-index форма `U_jPᵀg_j`. Не переносить подозрительную формулу из дублирующего раздела без проверки.
