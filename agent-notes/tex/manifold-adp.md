# Manifold ADP

## Модель

В ambient-пространстве `R^d` регрессионная функция локально имеет multi-index форму, но её EDR-подпространство зависит от точки:

```text
g(X_i) ≈ c_j + a_jᵀ P_j (X_i−x_j),
P_j ∈ R^(m×d),  P_jP_jᵀ=I_m.
```

Метод не требует явного задания manifold и не проецирует данные на него `[A-OVERVIEW]`. Он оценивает семейство локальных подпространств `P_j` и поощряет их плавное изменение для близких центров. Источник вводит две шкалы: `h` для локальной аппроксимации ответа и более крупную `h_M` для сходства локальных подпространств (`h_M≫h` на старте) `[A-SCALES]`.

## Данные для локальных моделей

Для каждого центра `x_j` по наблюдениям строятся `w_ij`, `N_j`, `Xbar_j`, `I_j`, `U_j` так же, как в [multi-index ADP](multi-index-adp.md). При центрировании локальный intercept сокращается, и

```text
I_j ≈ U_j P_jᵀ a_j.
```

В manifold-спецификации из `manifold-ade.tex` локальные directional moments нормированы на `N_j`, а ошибка умножается на `N_j` `[A-OBJECTIVE]`. Это согласуется с multi-index ADP `[X-MI-PRE]`, `[X-MI-AO]`. Дублированный раздел `Manifold learning` в `manifold.tex` использует моменты с другой нормировкой и местами дополнительно оставляет intercept `f0_{jℓ} S_j` `[M-MAN-OBJ]`; не переносите эти формулы в одну цель без решения вопроса о масштабе и intercept.

## Соседство центров и функционал

Для центра-получателя `x_ℓ` задаются manifold-веса `[A-OBJECTIVE]`

```text
ω_{jℓ}=K(||T^M_ℓ (x_j−x_ℓ)||²),
```

которые выбирают соседние центры `j`, используемые для оценки `P_ℓ`. В ADP-формулировке базовая часть функционала `[A-OBJECTIVE]`:

```text
Σ_ℓ Σ_j N_j ω_{jℓ} ||I_j − U_j P_ℓᵀ a_{jℓ}||².
```

`a_{jℓ}∈R^m` — nuisance slope для пары «соседний центр `j`, локальная задача `ℓ`». Это позволяет общей матрице `P_ℓ` объяснять локальные directional moments в окрестности `x_ℓ`, не заставляя наклоны разных точек быть одинаковыми.

Согласование подпространств задаётся через проекторы, чтобы результат не зависел от поворота/знаков базиса `[A-OBJECTIVE]`:

```text
ε(P_j,P_ℓ) = ||P_j (I−P_ℓᵀP_ℓ)||_F²
            = m − tr(P_jᵀP_j P_ℓᵀP_ℓ).
```

Полный целевой функционал добавляет `λ_M Σ_ℓΣ_j ω_{jℓ} ε(P_j,P_ℓ)` `[A-OBJECTIVE]`. Для одинаковой размерности `m` эта потеря пропорциональна квадрату Frobenius-расстояния между проекторами и инвариантна к базису.

## Один шаг по каждой окрестности `ℓ`

Пусть текущие локальные подпространства `P_{j,init}` уже заданы `[A-ONESTEP]`.

1. Для всех соседей `j` оценить наклоны `a_{jℓ}` при фиксированном `P_{ℓ,init}` через LS:

   ```text
   a_{jℓ} = argmin_a ||I_j − U_j P_{ℓ,init}ᵀ a||².
   ```

2. Рассчитать массу manifold-соседства `W_ℓ=Σ_jω_{jℓ}` и усреднённый проектор соседей

   ```text
   E_ℓ = W_ℓ⁻¹ Σ_j ω_{jℓ} P_{j,init}ᵀP_{j,init},   0≤E_ℓ≤I.
   ```

   `E_ℓ` в общем случае не projector; это мягкая средняя структура соседей.

3. Расслабить ортогональность и найти `B_ℓ∈R^(m×d)` из

   ```text
   argmin_B Σ_j N_j ω_{jℓ} ||I_j−U_j Bᵀa_{jℓ}||²
               + λ_M W_ℓ tr(BᵀB(I−E_ℓ)).
   ```

   Это запись источника `[A-ONESTEP]` после сведения penalty к `E_ℓ`; там не приведён явный solver для общей LS-задачи.

4. Построить локальную структурную матрицу и восстановить ортонормированное подпространство:

   ```text
   J_ℓ = B_ℓᵀ [Σ_j N_j ω_{jℓ} a_{jℓ}a_{jℓ}ᵀ] B_ℓ.
   ```

   Взять `m` ведущих собственных направлений `J_ℓ` как `P_ℓ`, сохранить спектральные веса `Λ_ℓ` и использовать новые проекторы в следующем шаге. Матрица `J_ℓ` имеет ранг не выше `m` `[A-ONESTEP]`.

Повторить локальное обновление для всех `ℓ`; затем повторить one-step procedure несколько раз при инициализации/синхронизации `[A-ONESTEP]`.

## Старт и внешняя multiscale-итерация

1. Выбрать центры `x_j`, число направлений и три полосы `h_0`, `h_lin`, `h_M0`. Источник задаёт средние mass-критерии для наблюдений (`N_min`), локальной линейной регрессии (`N_lin`) и соседей-центров (`N_man`), с `h_M0≫h_0` `[A-INIT]`, `[A-MAIN]`.
2. По локальной affine-регрессии `Y` на `[1; X_i−x_j]` оценить `∇hat g(x_j)` `[A-INIT]`. Для каждого `ℓ` сгладить outer products:

   ```text
   J_ℓ,init = Σ_j N_j K(||x_j−x_ℓ||²/h_M0²) ∇hat g_j ∇hat g_jᵀ.
   ```

   Первые `m` eigenvectors задают `P_{ℓ,init}`. Затем выполнить несколько шагов согласования соседних базисов `[A-INIT]`.
3. Инициализировать observation tensors `T_j` изотропно, а manifold tensors `T^M_ℓ` изотропно с более широкой полосой. Main procedure `manifold-ade.tex` `[A-MAIN]` пересэмплирует `s` как нормированный `N(0,I)` вектор, пересчитывает directional moments с observation weights, для каждого `ℓ` выполняет пункты выше и получает `{P_ℓ,Λ_ℓ}`.
4. Уменьшать `h_k` и `h_{M,k}` множителем `a>1`. Обновлять оба семейства локализаторов по `P_j,Λ_j` и подбирать отдельные анизотропии `α_k`, `α_M,k` для соблюдения соответствующих mass-критериев. Затем пересчитать `w_ij` и `ω_{jℓ}` `[A-MAIN]`.
5. Остановиться у минимального `h`/`h_M` по критерию исходника `[A-MAIN]`. Рукопись отдельно перечисляет проверку ошибок, стоимости, памяти, чувствительности к `λ_M` и деградации при росте `d` как будущую экспериментальную работу, а не готовые результаты `[A-MAIN]`.

В дублирующем `manifold.tex` локализаторы выписаны в форме `[M-MAN-MAIN]`:

```text
T_j²   = α² h⁻² (I−P_jᵀP_j) + h⁻² J_j
T^M_ℓ² = α_M² h_M⁻² (I−P_ℓᵀP_ℓ) + h_M⁻² J_ℓ.
```

Перед реализацией проверьте нормировку `Λ` внутри `J`, поскольку она задаёт относительную ширину ядра вдоль EDR-направлений.

## Что в рукописях не совпадает или не закрыто

- В `manifold-ade.tex` ADP-вариант явно использует центрированные и нормированные moments и не содержит `f0_j S_j` `[A-OBJECTIVE]`, `[A-ONESTEP]`. Дублирующая секция в `manifold.tex` происходит из более общего multi-index изложения и сохраняет дополнительные переменные `[M-MAN-OBJ]`.
- Формула `J_ℓ` в `manifold-ade.tex` включает `N_j ω_{jℓ}` `[A-ONESTEP]`. В дублирующей копии `manifold.tex` сверяйте именно используемый вариант `[M-MAN-ONESTEP]`.
- В одном one-step отображении индекс наклона записан то как `a_{jℓ}`, то как общий `a_ℓ` `[A-ONESTEP]`; объединённая objective требует nuisance slope для каждой пары `(j,ℓ)`.
- Лемма о сведении manifold penalty к trace-форме помечена `please check` `[A-OBJECTIVE]`; сама проекторная идентичность следует из `P_jP_jᵀ=P_ℓP_ℓᵀ=I`, но напечатанное доказательство имеет неточную trace-строку.
- Основной цикл пересэмплирует направления из `N(0,I)` `[A-MAIN]`, хотя теоретическое описание допускает/предлагает `N(0,T_j²)` `[A-OBJECTIVE]`. Это отдельная настройка, влияющая на objective через конечный sketch.
- Таблица manifold-настроек не всегда перечисляет `N_man`, хотя инициализация и mass constraint от него зависят `[A-INIT]`, `[A-MAIN]`.
- Обе mass-проверки усреднены по центрам `[A-INIT]`, `[A-MAIN]`. Они не гарантируют достаточное число соседей в каждой отдельной локальной задаче; обязательно контролировать `N_j` и `W_ℓ`.
