# Single-index ADP

## Задача и целевая величина

Модель: `Y_i = f(βᵀX_i) + ε_i`, где `β ∈ R^d`, `||β||=1`. Тогда `∇g(x)=f'(βᵀx)β`, поэтому все локальные градиенты лежат на одной прямой. ADP оценивает эту прямую, не пытаясь восстановить весь `f`. `β` и `−β` эквивалентны; сравнивать направления нужно по модулю скалярного произведения.

Это именно раздел **Average derivative procedure**, а не более общий single-index алгоритм выше по `manifold.tex` `[M-SI-PRE]`: общий алгоритм отдельно оценивает локальные уровни `f0_j` и наклоны через `S_j`; центрированный ADP `[M-ADP-SI-PRE]` исключает константу и оставляет локальный производный коэффициент.

## Локальные статистики

На каждом центре `x_j` при заданных `T` и ядре:

```text
w_ij    = K(||T (X_i - x_j)||²)
N_j     = Σ_i w_ij
Xbar_j  = Σ_i w_ij X_i / N_j
I_j,s   = Σ_i w_ij Y_i <X_i - Xbar_j, s> / N_j
u_j,s   = Σ_i w_ij (X_i - Xbar_j) <X_i - Xbar_j, s> / N_j
U_j     = rows(u_j,sᵀ),       I_j = vector(I_j,s)
```

Размеры: `I_j ∈ R^P`, `U_j ∈ R^(P×d)`. Локальная аппроксимация
`f(βᵀX_i) ≈ f_j + q_j βᵀ(X_i−x_j)` даёт

```text
I_j ≈ q_j U_j β,     q_j ≈ f'(βᵀx_j).
```

Слагаемое `f_j` исчезает, так как `Σ_i w_ij (X_i−Xbar_j)=0`. Это ключевой шаг ADP: наблюдаемые directional moments аппроксимируют локальные производные, умноженные на общий индекс.

### Нормировка в источниках

Выше приведена **нормированная** версия из single-index части `multiindex.tex` `[X-SI-PRE]`. Для взвешенного варианта, который используется в AO и main procedure `[X-SI-AO]`, цель имеет вид

```text
L(β,q) = Σ_j N_j ||I_j − q_j U_j β||²,     ||β||=1.
```

В ADP-разделе `manifold.tex` `[M-ADP-SI-PRE]` `I_j,s` и `u_j,s` записаны без деления на `N_j`. Если `I_raw=N_j I` и `U_raw=N_j U`, то невзвешенная сумма квадратов raw-остатков равна нормированной цели с весами `N_j²`; при дополнительном множителе `N_j` — с весами `N_j³`. Поэтому формулы из этих двух разделов нельзя считать эквивалентными при неодинаковых локальных массах. Для согласованного изложения с multi-index и manifold ADP используйте нормированную конвенцию, пока отдельное решение не выберет другую.

## Одношаговая alternating optimization

Вход: `I_j`, `U_j`, массы `N_j`, начальный единичный `β₀`, штраф `λ≥0`; исходные AO-формулы находятся в `[X-SI-AO]` и `[M-ADP-SI-AO]`.

1. При фиксированном `β₀` оценить локальные производные:

   ```text
   q_j = <I_j, U_j β₀> / ||U_j β₀||².
   ```

   Это scalar least squares. В формуле источника `[M-ADP-SI-AO]` нет стабилизатора знаменателя; если `||U_jβ₀||` мал, локальный наклон не определён надёжно.

2. При фиксированных `q_j` решить расслабленную задачу по `β`:

   ```text
   (Σ_j N_j q_j² U_jᵀU_j + λI) β_raw
       = Σ_j N_j q_j U_jᵀI_j + λβ₀.
   ```

   TeX `[M-ADP-SI-AO]` пишет это через явную обратную матрицу. В вычислительном коде следует решать систему устойчивым solver-ом; источники не задают такой реализации.

3. `β₁ = β_raw / ||β_raw||`; затем повторять, подавая предыдущий `β₁` как новый вход, до `k_max`.

`λ` стабилизирует промежуточное unconstrained обновление относительно текущего направления. После проекции нормировкой это не точная минимизация исходной задачи на сфере. Источник `[M-ADP-SI-AO]` отмечает формулу как требующую проверки и не доказывает сходимость AO.

## Старт и внешний structure-adaptive цикл

1. Выбрать центры `x_j`. Для начального градиентного старта взять изотропные веса с полосой `h_lin` и локально оценить affine-регрессию `[1; X_i−x_j] → Y_i` `[X-SI-INIT]`. В источнике требуется `n_lin>d+1`; градиенты `∇hat g(x_j)` собрать в `J=Σ_j ∇hat g_j ∇hat g_jᵀ`, взять главный собственный вектор как `β_init` `[M-ADP-SI-INIT]`.
2. Изотропный старт: `w_ij=K(||X_i−x_j||²/h_0²)`. `h_0` выбирается из условия на среднюю массу `J⁻¹Σ_jΣ_i w_ij ≥ N_min` `[M-ADP-SI-INIT]`.
3. На каждом уровне `k`: построить веса, пересчитать `Xbar`, `N`, `I`, `U`; запустить AO; сохранить `β_k` `[M-ADP-SI-MAIN]`.
4. Если уровень полосы не достиг `h_min`, уменьшить `h_k=h_{k−1}/a`, обновить локализатор `T_k` из нового `β` и выбрать `α_k` так, чтобы средняя локальная масса оставалась не меньше `N_min` `[X-SI-MAIN]`, `[M-ADP-SI-MAIN]`.
5. Остановиться при условии источника `h_k/a < h_min` `[X-SI-STOP]` либо выбрать уровень по ошибке прогноза `err_k`, если нужен data-driven stopping. Это предложенное в источнике правило, а не доказанное свойство.

Для single-index в `multiindex.tex` `[X-SI-ANISO]` структура-анизотропия записана как

```text
T² = h⁻² [ α²(I−ββᵀ) + ββᵀ ]
   = h⁻² [ α²I + (1−α²)ββᵀ ].
```

Она сужает окрестность вдоль найденного индекса и оставляет более широкую в ортогональных направлениях. Но ADP-копия в `manifold.tex` `[M-ADP-SI-MAIN]` задаёт `T²=h⁻²(α²I+ββᵀ)`; это другая формула. В общем теоретическом абзаце `[M-SI-ANISO]` также есть запись без множителя `(1−α²)`. Не подменяйте один вариант другим молча.

Сэмплирование направлений в исходниках тоже расходится: теоретическое описание предлагает `s ∝ N(0,T²)` `[X-SI-ANISO]`, а main procedure — `s ∝ N(0,I)` `[X-SI-MAIN]`. Считайте закон `s` открытым выбором спецификации.

## Границы и проверки перед реализацией

- Среднее условие на `N_j` не исключает пустые или вырожденные отдельные окрестности. Нужны проверки `N_j`, `||U_jβ||`, конечности решения и нормы `β_raw`.
- Локальная линейная инициализация строит систему порядка `d+1` в каждом центре; при больших `d` она может быть плохо обусловлена. Источник записывает обратную матрицу и не задаёт регуляризацию.
- Табличные настройки (`N_min≈10`, `J` между `n/N_min` и `n`, `P≈min(N_min,d)`, `a≈√2`) — исследовательские ориентиры, не математические ограничения `[M-SI-TUNE]`, `[X-SI-DOE]`.
- В исходниках `K(t)=(1−t²)_+`, но в весах в `K` передаётся квадрат нормированного расстояния `[X-SI-PRE]`, `[M-ADP-SI-PRE]`. Зафиксируйте это буквальное соглашение при сравнении формул.
- В общих single-index preliminaries записано `T=h⁻²I`, но рядом вес раскрывается как `K(h⁻²||X_i−x_j||²)` `[M-SI-PRE]`, `[X-SI-PRE]`; буквальная подстановка `T` в `K(||TΔ||²)` дала бы `h⁻⁴`. ADP-инициализация отдельно задаёт `T_0=h_0⁻¹I` `[M-ADP-SI-INIT]`. Не переносите одну из этих записей молча.
