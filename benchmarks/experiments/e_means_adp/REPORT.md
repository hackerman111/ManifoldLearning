# Результат попытки интеграции идей e-means в анизотропный ADP

2026-11-13. **Отрицательный отбор. Улучшение времени с сохранением качества
не подтверждено. Полное решение задачи улучшения EDR не получено.**
Исходный ADP, его API и defaults сохранены. Модификация осталась отдельным
экспериментальным решателем; применять её как замену original20 оснований нет.

## Что сохранено и что проверено

Использована статья [e-means, arXiv:2611.09501v1](https://arxiv.org/html/2611.09501v1),
раздел3 и приложениеH. Её результаты относятся к кластеризации. Перенесена
отправная идея минибатчей, cosine EMA и финальной полной обработки; численные
scaling laws и заявленные ускорения статьи на ADP не переносились.

Исходными остались центры, initializer, анизотропные ядровые веса,
локальные I/U и mass, sketch-направления, поиск alpha, расписание h,
Grassmann profile и outer best-step criterion. Веса следующих масштабов
естественно меняются при изменении оценённого базиса. Во всех68 Python-файлах
пакета ADP совпадение с frozen source подтверждено хешами; исходники не правились.

Четыре семейства рассмотрены до выбора основного пути:

| Семейство | Предположения и строгий результат | Точный пробел / решение |
| --- | --- | --- |
| EMA локальных sufficient statistics | При фиксированных весах и проекциях EMA равна статистике с явно перевзвешенными наблюдениями | Меняет estimator; старые моменты не относятся к новой геометрии. Нет доказательства EDR-выигрыша; не выбран |
| EMA внешней анизотропной геометрии | PSD/gauge identity; точная формула matrix MSE при независимых unbiased ошибках одного target и детерминированных весах | Эти условия для adaptive ADP не установлены; сама формула не гарантирует снижение MSE при разных дисперсиях. Усреднение может испортить даже точный текущий EDR. Не выбран |
| Минибатчи fixed-profile solver + full finalization | Сохраняет полный target; сравнение входа/предложений и финальный guard дают спуск относительно входа при точной оценке profile | Нет сравнения с original20, глобальной сходимости или EDR-гарантии. Выбран для frozen проверки |
| Удаление / revival неинформативных центров | При U_j=0 вклад — известная константа; точное исключение уже реализовано | Малый U_j не означает малый вклад при tau=0; revival меняет estimator. Нового точного ускорения не найдено |

Полные выводы, размерности, оценки операций/памяти, доказательства и
контрпримеры: [MATH.md](MATH.md). Независимый разбор и исправления перед

## Протокол и измерения

320/320 fit успешны:8 задач x10 seed1131400..1131409 x4 метода;
80 полных пар на метод,0 пропусков,0 исключённых ошибок. Семь семейств из
существующего каталога при n800/d20/m3/J200; additive scale-check при
n2000/d50/m3/J300. N_phi12,N_loc20,N_lin2d; Gaussian X, noise.3.
Данные/истинный базис/шум/инициализация/sketch RNG одинаковы внутри каждой пары.
Минибатчи имеют отдельный seed, общий для mini и mini_ema. Веса имеют исходный
профиль K(u)=max(1-u²,0), u — исходный нормированный квадрат расстояния.

original20 — текущий public combined20. full6 — тот же solver с6 полными
шагами. mini —2 прохода по4 батчам, один исходный шаг на батч, затем4 полных
шага. mini_ema дополнительно рассматривает EMA проекторов как старт финального
solve. Каждый раз полный guard включает входной базис. Номинально это6
полноцентровых step-equivalent, но повторные SVD/валидация/guard evaluations
не позволяют считать этот бюджет теоремой ускорения20/6.

Source/environment/protocol заморожены до исходов; все80 входных блоков и
их SHA256 записаны до первого selection fit. Workers выполняли snapshot,
создавали новый solver на fit, использовали float64 и один BLAS thread.
Порядок методов перемешивался. Fit time исключает импорты/запуск процесса;
process time также сохранён. Хост общий с другими заданиями; абсолютное
время не следует переносить на изолированный запуск.

RSS — максимум VmHWM/VmRSS с опросом25ms и worker ru_maxrss, включая Python
и импорты. Cap2048MiB опрашиваемый, timeout120s. Нет утверждения об экономии
RAM. Исходный U и full-pool distances по-прежнему вычисляются целиком.

## Самый сильный строго доказанный результат и точный пробел

Для точной оценки одного фиксированного profile F, включение входа B0 в
набор кандидатов даёт F(Bc)<=F(B0). Выбор между Bc и финальной попыткой Bp
по тому же полному F даёт F(Br)<=F(Bc). Это полный простой proof спуска
относительно ВХОДА одного масштаба; он не сравнивает Br с original20.
PSD EMA через прямоугольный фактор gauge-invariant; при спектральном зазоре
его top-m пространство оптимально приближает EMA ранговым проектором в
Frobenius-норме. Это не утверждение о true EDR.

Реализация использует исходный float64 rank cutoff. Неотрицательный спектр,
неединственность при нулевом зазоре, rank loss и conditioning рассмотрены в
MATH. Near-cutoff truncation может отличаться от идеального min_g. Поэтому
unconditional программная гарантия относится к сравниваемым ЧИСЛЕННЫМ
значениям; строгий real-arithmetic proof требует указанного домена/точной
оценки. Проверки не являются interval-arithmetic сертификатами.

**Оставшийся пробел:** отсутствует доказательство, что такой bounded optimizer
даёт меньшую EDR, сохраняет EDR original20 или сходится быстрее в полном
адаптивном ADP. Даже точное снижение F не даёт нужного вывода: в MATH
приведён полноранговый контрпример F:1->0 при EDR:0->1/sqrt(5).
Frozen эксперимент дополнительно не прошёл заранее заданные критерии.
Частные положительные срезы и fixed-scale proof не выдаются за полное решение.
