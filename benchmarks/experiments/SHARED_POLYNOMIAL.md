# Экспериментальный общий полиномиальный профиль

Метод оценивает общий многоиндексный нелинейный отклик по всей выборке и
уточняет начальное подпространство ADP. Его кубическая модель включает все
смешанные полиномиальные члены; известная истинная функция не используется.

```python
from experiments.shared_polynomial import fit

# X: массив (n, d), y: массив (n,), m: известная размерность индекса
result = fit(X, y, m=3, seed=42)
basis = result.basis                  # ортонормированные столбцы, (d, m)
print(result.diagnostics["stop_reason"])
print(result.diagnostics["gradient_norm"])
print(result.diagnostics["gradient_rank_ok"])
print(result.diagnostics["tangent_rank_ok"])
```

Значение `stationary` означает достижение численного порога градиента, но
не глобального минимума и не правильного восстановления. Два rank-флага
проверяют только численные матрицы на конкретной выборке: шум тоже способен
придать им полный ранг. Наличие у ответа значимого компонента в четвёртом и
более высоком порядке может привести к потере истинного направления.

Текущий default исследования — степень 3, 60 внутренних шагов и инициализация
двусторонним full-moment ADP. Полное время `fit_seconds` включает этот старт.
Спектральное демпфирование входит только в оптимизационный шаг; постоянный
штраф полиномиальных коэффициентов не добавлен. Для больших m число
коэффициентов `binom(m+3,3)` и размер Schur-системы `m(d-m)` растут, поэтому
стоимость и пригодность следует измерять отдельно.
