# Gaussian Stein/Fourier EDR objective

Экспериментальный оцениватель для **известного закона X ~ N(0,I)**.
Размерность условного среднего предполагается равной заданному `index_dim`.
Применение к произвольным, просто центрированным или нормированным признакам
не имеет приведённой ниже гарантии. Текущий ADP и его настройки не меняются.

Проверка на 120 парных задачах n=5000,d=25: время укладывается в лимит 3×,
но EDR хуже ADP; selection-гейт провален. Этот вариант остаётся
экспериментальным. Числа и границы вывода: [отчёт](../results/verification/gaussian-fourier-20261025/report.md).

```python
from experiments.gaussian_fourier import fit, objective

result = fit(X, y, index_dim=3, n_frequencies=256,
             frequency_scale=2.0, seed=123)
B = result.basis                 # (d,m), ортонормированные столбцы
Z = X @ B
value, gradient = objective(B, result.basis)
print(result.diagnostics)
```

`frequency_scale` задаёт среднеквадратичную норму случайной частоты;
первая из частот равна нулю. Это параметр метода, а не масштаб признаков.
`fit` не принимает истинное подпространство и не использует его для выбора
частот. Невозможный ранг, неположительное выбранное собственное значение
или численно неоднозначная граница подпространства вызывают `ValueError`.

Для NPZ-файла с массивами `X` и `y`:

```bash
python -m experiments.gaussian_fourier data.npz --index-dim 3 \
  --frequency-scale 2 --seed 123 --output fit.npz
```

Результат содержит `basis`, `eigenvalues` и JSON-строку `diagnostics`.
`sample_recovery_certified=False` означает, что статистический сертификат
восстановления по данной конечной выборке не вычислен.

## Что доказано

Пусть E[Y|X]=f(B_*^T X), B_*^T B_*=I_m. Для частот, независимых от данных,
тождество Стейна даёт

    v(t) = E[Y (X-i*t) exp(i*t^T X)]
         = E[grad_X E[Y|X] exp(i*t^T X)] in span(B_*).
    M = mean_t Re(v(t) v(t)^H).

При rank(M)=m проектор на образ M равен P_*=B_* B_*^T. Тогда для B^T B=I_m

    F_pop(B) = 1-tr(B^T P_* B)/m = EDR(B,B_*)^2.

Это точное равенство, включая одинаковый вес слабых и сильных направлений.
Предполагаются условия интегрирования по частям и конечные вторые моменты
Y и Y*X. Для конечного набора частот условие полного ранга существенно;
оно не обеспечивает нижней границы силы сигнала.

Матрица M оценивается U-статистикой по различным наблюдениям; смещение от
самопроизведений выборочных средних удаляется аналитически. Выборочная
матрица может иметь отрицательные собственные значения. Её ведущие m
собственных векторов дают проектор P_hat и точный минимум выборочной цели

    F_hat(B) = 1-tr(B^T P_hat B)/m.

Поэтому новый оптимизатор — спектральное разложение; повторные шаги
Гаусса—Ньютона здесь не требуются.

## Где заканчивается гарантия

Нулевой минимум F_hat означает совпадение с оценённым подпространством.
Он не доказывает совпадения с истинным B_*. Если отдельно сертифицировано
||M_hat-M||_op<=delta и lambda_hat_m>0, то

    EDR(B_hat,B_*) <= min(1,delta/lambda_hat_m),
    sup_B |F_hat(B)-F_pop(B)| <= min(1,delta/lambda_hat_m).

`perturbation_bound(lambda_hat_m, delta)` вычисляет только эту условную
границу: delta должен быть доказанной внешней границей ошибки матрицы.
Bootstrap-разброс не подставляется вместо неё. Произвольное уменьшение
выборочной цели не гарантирует уменьшения истинного EDR; при указанной
границе это верно для уменьшения, превышающего удвоенную погрешность цели.

Время построения: O(ndR+nd²+d³). Дополнительная пиковая память:
O(nd+n*b+dR+d²), где b — размер блока частот. Матрицы n*n не строятся.
Временной лимит 3× проверяется полными парными fit, а не этой оценкой сложности.

в протоколе и независимо проверены. Практический результат эксперимента
нужно читать отдельно от популяционного доказательства.
