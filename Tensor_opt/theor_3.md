В `sin-mul.tex` веса имеют вид

[
w_{ij}=K(q_{ij}),
\qquad
q_{ij}=|T_k(X_i-x_j)|^2,
]

а kernel задан как

[
K(t)=(1-t^2)_+.
]

Поэтому в точной арифметике

[
\boxed{w_{ij}=0\iff q_{ij}\ge 1.}
]

Начальный (h_0) выбирается как наименьший bandwidth, удовлетворяющий ограничению на среднюю локальную массу, а на следующих multi-index шагах (h_k) уменьшается геометрически и (\alpha_k) определяется условием на массу.

Ниже все pruning-условия сохраняют **ровно те же веса**, пока явно не сказано обратное.

## 1. Независимые семейства оптимизаций

| Семейство                 | Механизм                                    | Точный результат                         |
| ------------------------- | ------------------------------------------- | ---------------------------------------- |
| Алгебраический screening  | нижняя граница для (q_{ij})                 | усиленное условие (w_{ij}=0)             |
| Иерархические проекции    | последовательно уточняемые lower bounds     | pruning до чтения всех (d) координат     |
| Параметрический screening | использовать сам алгоритм выбора (h,\alpha) | support и параметр находятся совместно   |
| Exact range search        | искать только точки, способные иметь (w>0)  | исключение перебора (Jn) пар             |
| Reuse между итерациями    | старые расстояния и тензоры                 | не считать повторно неизменную геометрию |
| Blockwise early exit      | частичная норма (                           | \Delta                                   | ^2) | остановка вычисления расстояния внутри пары |

Самый сильный вариант получается из их комбинации.

# 2. Single-index: прежнее условие можно строго усилить

Положим

[
\Delta_{ij}=X_i-x_j,
\qquad
D_{ij}=|\Delta_{ij}|^2,
\qquad
s_{ij}=\beta^\top\Delta_{ij}.
]

Для

[
T^2
===

h^{-2}
\left(
\alpha^2I+\beta\beta^\top
\right),
\qquad
|\beta|=1,
]

имеем точно

[
q_{ij}
======

\frac{
\alpha^2D_{ij}+s_{ij}^2
}{h^2}.
]

Следовательно,

[
\boxed{
w_{ij}=0
\iff
\alpha^2D_{ij}+s_{ij}^2\ge h^2.
}
\tag{1}
]

Если (D_{ij}) уже известна, это окончательное точное условие.

### Если известна только одномерная проекция

Так как

[
D_{ij}\ge s_{ij}^2,
]

то

[
q_{ij}
\ge
\frac{(1+\alpha^2)s_{ij}^2}{h^2}.
]

Получаем

[
\boxed{
|s_{ij}|
\ge
\frac{h}{\sqrt{1+\alpha^2}}
\quad\Longrightarrow\quad
w_{ij}=0.
}
\tag{2}
]

Это сильнее прежнего условия

[
|s_{ij}|\ge h.
]

Например, при (\alpha=1)

[
\frac{h}{\sqrt2}\approx0.707h,
]

поэтому интервал потенциально ненулевых весов по активной координате сужается примерно на (29.3%).

### Теорема об оптимальности

Условие (2) представляет **наилучшую возможную универсальную проверку, использующую только (s=\beta^\top\Delta)**.

Доказательство. Для фиксированного (s)

[
|\Delta|^2\ge s^2,
]

и минимум достигается при

[
\Delta=s\beta.
]

Поэтому

[
\inf_{\Delta:\beta^\top\Delta=s}q(\Delta)
=========================================

\frac{(1+\alpha^2)s^2}{h^2}.
]

Если эта величина меньше 1, существует (\Delta=s\beta), для которого (w>0). Значит, никакая более агрессивная проверка, зависящая только от (s), не может быть exact.

# 3. Иерархический screening для single-index

Условие можно постепенно усиливать.

Пусть

[
Q_r\in\mathbb R^{r\times d},
\qquad
Q_rQ_r^\top=I_r,
]

причём

[
\beta\in\operatorname{row}(Q_r).
]

Положим

[
z_{ij}=Q_r\Delta_{ij}.
]

Тогда

[
D_{ij}\ge|z_{ij}|^2,
]

откуда

[
\boxed{
q_{ij}
\ge
L^{(r)}_{ij}
:=
\frac{
\alpha^2|z_{ij}|^2+s_{ij}^2
}{h^2}.
}
\tag{3}
]

Поэтому

[
L^{(r)}_{ij}\ge1
\quad\Longrightarrow\quad
w_{ij}=0.
]

При (r=1) получаем условие (2).

При увеличении подпространства

[
\operatorname{row}(Q_r)
\subseteq
\operatorname{row}(Q_{r+1}),
]

имеем

[
L^{(r)}
\le
L^{(r+1)}
\le
q.
]

При

[
r=d
]

получаем равенство

[
L^{(d)}=q.
]

То есть можно сделать каскад:

[
1D
\rightarrow
4D
\rightarrow
16D
\rightarrow
\text{полное }dD.
]

Для большинства пар вычисления остановятся на раннем уровне.

# 4. Multi-index: здесь прежнее условие уже оптимально

Пусть

[
P\in\mathbb R^{m\times d},
\qquad
PP^\top=I_m,
\qquad
\Lambda\succeq0,
]

и

[
T^2
===

h^{-2}
\left[
\alpha^2(I-P^\top P) +
P^\top\Lambda P
\right].
]

Обозначим

[
u=P\Delta.
]

Тогда

[
\boxed{
q(\Delta)
=========

\frac{
\alpha^2
\left(
|\Delta|^2-|u|^2
\right) +
u^\top\Lambda u
}{h^2}.
}
\tag{4}
]

Отсюда

[
\boxed{
u^\top\Lambda u\ge h^2
\quad\Longrightarrow\quad
w=0.
}
\tag{5}
]

Это условие мы уже получили раньше.

### Усилить его только через (P\Delta) невозможно

Для фиксированного (u=P\Delta)

[
|\Delta|^2\ge|u|^2.
]

Минимум достигается при

[
\Delta=P^\top u.
]

Тогда ортогональная компонента равна нулю и

[
q_{\min}(u)
===========

\frac{u^\top\Lambda u}{h^2}.
]

Следовательно,

[
\boxed{
\inf_{\Delta:P\Delta=u}q(\Delta)
================================

\frac{u^\top\Lambda u}{h^2}.
}
]

Поэтому (5) уже представляет максимальное exact-screening условие, использующее **только** (P\Delta).

Это закрывает один из пробелов предыдущего анализа: усиление multi-index требует дополнительной информации об ортогональной части.

---

# 5. Усиленное multi-index условие через небольшое superspace

Пусть

[
Q_r\in\mathbb R^{r\times d},
\qquad
r>m,
]

и

[
\operatorname{row}(P)
\subseteq
\operatorname{row}(Q_r).
]

Тогда

[
P=RQ_r,
\qquad
R\in\mathbb R^{m\times r},
\qquad
RR^\top=I_m.
]

Обозначим

[
z=Q_r\Delta,
\qquad
u=Rz=P\Delta.
]

Так как

[
|\Delta|^2\ge|z|^2,
]

из (4):

[
\boxed{
q(\Delta)
\ge
L_r(z)
======

\frac{
\alpha^2
\left(
|z|^2-|Rz|^2
\right) +
(Rz)^\top\Lambda(Rz)
}{h^2}.
}
\tag{6}
]

Следовательно,

[
\boxed{
\alpha^2
\left(
|z|^2-|Rz|^2
\right) +
(Rz)^\top\Lambda(Rz)
\ge h^2
\Longrightarrow
w=0.
}
\tag{7}
]

Это строго сильнее (5), поскольку добавляется неотрицательный член

[
\alpha^2
\left(
|z|^2-|Rz|^2
\right).
]

И это снова наилучшая lower bound по известному (z=Q_r\Delta): равенство достигается при

[
\Delta=Q_r^\top z.
]

---

# 6. Именно это особенно полезно для manifold

Если

[
P_j=R_jP__,
\qquad
P__\in\mathbb R^{m_s\times d},
\qquad
m<m_s\ll d,
]

то берём

[
z_{ij}=P_*(X_i-x_j).
]

Предыдущее manifold-условие использовало только

[
(P_j\Delta)^\top\Lambda_j(P_j\Delta).
]

Теперь получаем строго более сильное:

[
\boxed{
\alpha_j^2
\left[
|z_{ij}|^2
----------

|R_jz_{ij}|^2
\right] +
(R_jz_{ij})^\top
\Lambda_j
(R_jz_{ij})
\ge h_j^2
\Longrightarrow
w_{ij}=0.
}
\tag{8}
]

Всё условие считается в размерности (m_s), а не (d).

Таким образом, идея общего manifold-superspace даёт не только более дешёвый screening. Она **математически усиливает саму нижнюю границу** по сравнению с использованием одного (P_j\Delta).

# 7. Как выбрать дополнительные screening-направления

Пусть multi-index пространство (P) уже известно и мы хотим добавить (r-m) направлений

[
V\subset P^\perp.
]

Дополнительный член lower bound:

[
\alpha^2|V\Delta|^2.
]

Для набора потенциальных пар (\mathcal C) рассмотрим

[
C_\perp
=======

\sum_{(i,j)\in\mathcal C}
\Pi_\perp
\Delta_{ij}\Delta_{ij}^\top
\Pi_\perp,
\qquad
\Pi_\perp=I-P^\top P.
]

Тогда

[
\sum_{\mathcal C}|V\Delta_{ij}|^2
=================================

\operatorname{tr}(VC_\perp V^\top).
]

По принципу Куранта-Фишера максимальное значение среди всех ортонормированных (r-m) направлений достигается на главных собственных векторах (C_\perp).

То есть для фиксированного числа screening-координат оптимальный по **средней захваченной ортогональной энергии** выбор:

[
\boxed{
V=
\text{top eigenvectors of }C_\perp.
}
]

Это не доказывает максимум числа отброшенных пар, поскольку pruning использует threshold, а не сумму lower bounds. Но средняя величина добавки к lower bound оптимальна точно.

На практике полный (C_\perp) строить не стоит. Можно брать:

- глобальные PCA-направления;
- PCA по выборке surviving pairs;
- уже имеющийся manifold superspace.

Любой такой выбор сохраняет exactness. Меняется только эффективность pruning.

# 8. Сам алгоритм выбора (h) можно сделать exact без binary search

Это отдельная линия.

В файле

[
K(t)=(1-t^2)_+.
]

Пусть при фиксированной геометрии

[
q_r=\frac{c_r}{h^2},
\qquad
c_r\ge0,
]

где (r) нумерует все пары.

Тогда

[
w_r
===

\left(
1-\frac{c_r^2}{h^4}
\right)_+.
]

Положим

[
y=h^4,
\qquad
e_r=c_r^2.
]

Тогда

[
w_r=(1-e_r/y)_+.
]

Целевая суммарная масса:

[
M(y)
====

\sum_r(1-e_r/y)_+.
]

Пусть

[
L=J,n_{\min}.
]

Нужно найти минимальный (y), для которого

[
M(y)\ge L.
]

На интервале между соседними breakpoint-ами (e_r) активное множество постоянно. Если в нём (N_A) элементов и

[
S_A=\sum_{r\in A}e_r,
]

то

[
M(y)
====

N_A-\frac{S_A}{y}.
]

Уравнение

[
M(y)=L
]

имеет явное решение

[
\boxed{
y__=
\frac{S_A}{N_A-L},
\qquad
h__=
y_*^{1/4}.
}
\tag{9}
]

Нужно только найти interval, содержащий (y_*).

### Начальный (h_0)

В изотропном случае

[
c_{ij}=|X_i-x_j|^2.
]

Следовательно,

[
e_{ij}=|X_i-x_j|^4.
]

Так можно получить **точно тот (h_0), который определён в `sin-mul.tex` как минимальный допустимый**, а не приближение бинарным поиском.

Точно тот же массив расстояний можно использовать для (h_{\rm lin}), меняется только target (L).

# 9. Полная сортировка тоже не обязательна

Наивная реализация (9):

[
O(N\log N),
\qquad
N=Jn,
]

из-за сортировки breakpoint-ов.

Но полный порядок breakpoint-ов не нужен. Нужно найти только интервал, содержащий (y_*).

Можно использовать selection:

1. взять median breakpoint;
2. partition массива;
3. одновременно посчитать число и сумму (e_r) слева;
4. вычислить (M) в median;
5. отбросить половину, в которой корня быть не может;
6. повторить.

С deterministic median-of-medians каждая итерация уменьшает текущий массив на постоянный коэффициент.

Стоимость:

[
N+\frac{N}{2}+\frac{N}{4}+\cdots
================================

O(N).
]

Поэтому после вычисления (e_{ij})

[
\boxed{
h_0
\text{ можно найти точно за }O(Jn)
}
]

арифметических операций и сравнений, не используя binary search по (h).

Это сильнее обычного поиска по числовому параметру.

# 10. Ещё интереснее подбор (\alpha)

Для фиксированного (h) положим

[
z=\alpha^2.
]

И single-, и multi-index можно записать как

[
q_r(z)
======

\frac{a_rz+b_r}{h^2},
\qquad
a_r,b_r\ge0.
]

Для single-index:

[
a_{ij}=D_{ij},
\qquad
b_{ij}=s_{ij}^2.
]

Для multi-index:

[
a_{ij}
======

D_{ij}-|P\Delta_{ij}|^2,
]

[
b_{ij}
======

(P\Delta_{ij})^\top
\Lambda(P\Delta_{ij}).
]

Вес:

[
w_r(z)
======

\left[
1-
\frac{(a_rz+b_r)^2}{h^4}
\right]_+.
\tag{10}
]

Поскольку

[
a_r\ge0,
]

каждый вес не возрастает с (z), следовательно

[
M(z)=\sum_rw_r(z)
]

тоже не возрастает.

# 11. Как именно надо выбирать (\alpha)

Если ограничение имеет вид

[
M(\alpha^2)\ge L,
]

то допустимое множество представляет интервал

[
0\le\alpha\le\alpha_*.
]

Поэтому sparsity-optimal выбор:

[
\boxed{
\alpha_*
========

\sup
\left{
\alpha\in[0,1]:
M(\alpha^2)\ge L
\right}.
}
\tag{11}
]

### Почему именно максимальное (\alpha)

Для

[
\alpha_1\le\alpha_2
]

имеем

[
q_r(\alpha_1)\le q_r(\alpha_2).
]

Следовательно,

[
\operatorname{supp}w(\alpha_2)
\subseteq
\operatorname{supp}w(\alpha_1).
]

То есть среди всех (\alpha), удовлетворяющих условию на массу, максимальное (\alpha):

[
\boxed{
\text{минимизирует число ненулевых весов}.
}
\tag{12}
]

Это точное утверждение.

В текущем `sin-mul.tex` сказано только, что (\alpha_k) «fixed by the condition», то есть extremum не указан.

В более старых версиях встречается формулировка «smallest value ensuring». Она противоречит монотонности: если некоторое (\alpha>0) допустимо, то (\alpha=0) имеет не меньшую массу. Поэтому «smallest» почти всегда выбирает крайнее значение (0), то есть **максимально широкий ортогональный support**.

Для вычислений и для идеи «минимальная окрестность при достаточной массе» нужен именно `largest feasible`.

# 12. (\alpha) также можно подобрать без binary search

Из (10) пара активна тогда и только тогда, когда

[
a_rz+b_r<h^2.
]

Если (a_r>0), её breakpoint:

[
\boxed{
\tau_r
======

\frac{h^2-b_r}{a_r}.
}
\tag{13}
]

Если

[
b_r\ge h^2,
]

то

[
w_r(\alpha)=0
]

для **всех** (\alpha\ge0). Эту пару можно выбросить ещё до вычисления (\alpha).

На интервале между соседними (\tau_r) active set фиксирован. Тогда

[
M(z)
====

N_A-
\frac{
A_2z^2+2A_1z+A_0
}{h^4},
]

где

[
A_2=\sum_{r\in A}a_r^2,
]

[
A_1=\sum_{r\in A}a_rb_r,
]

[
A_0=\sum_{r\in A}b_r^2.
]

Условие

[
M(z)=L
]

сводится к одному квадратному уравнению:

[
A_2z^2+
2A_1z+
A_0-h^4(N_A-L)=0.
]

Если (A_2>0),

[
\boxed{
z_*=
\frac{
-A_1+
\sqrt{
A_1^2-A_2[A_0-h^4(N_A-L)]
}
}{
A_2
}.
}
\tag{14}
]

После нахождения нужного breakpoint-интервала получаем

[
\alpha__=\sqrt{z__}.
]

Как и для (h), нужный interval можно найти selection-алгоритмом за (O(Jn)) после вычисления (a_r,b_r).

То есть binary search по (\alpha), который несколько раз пересчитывает все (Jn) весов, математически не нужен.

# 13. Если использовать квантиль массы, структура ещё удобнее

У тебя ранее рассматривалось правило

[
Q_{0.1}
\left{
M_j(\alpha)
\right}
\ge n_{\min},
]

то есть достаточная масса должна быть как минимум у (90%) центров.

Для каждого центра отдельно определим

[
\alpha_j^*
==========

\sup
\left{
\alpha:
M_j(\alpha)\ge n_{\min}
\right}.
]

Тогда центр (j) удовлетворяет условию при (\alpha) тогда и только тогда, когда

[
\alpha\le\alpha_j^*.
]

Поэтому максимальное глобальное (\alpha), при котором условие выполняется для (90%) центров, есть соответствующая нижняя квантиль множества

[
{\alpha_j^*}_{j=1}^J.
]

То есть:

1. точно вычислить каждый локальный breakpoint (\alpha_j^*);
2. сделать `select` нужной квантили;
3. получить глобальный (\alpha).

Полной сортировки (J) значений опять не требуется.

Аналогично для (h_0): если

[
h_j^*
=====

\inf
\left{
h:M_j(h)\ge n_{\min}
\right},
]

то условие достаточной массы у (90%) центров задаёт соответствующую верхнюю квантиль ({h_j^*}). Такой квантильный вариант уже рассматривался в твоём анализе параметров как более устойчивый к неоднородной плотности.

# 14. Exact range search вместо проверки всех (Jn) пар

Для single-index условие ненулевого веса требует

[
|\beta^\top(X_i-x_j)|
<
\frac{h}{\sqrt{1+\alpha^2}}.
]

Введём

[
z_i=\beta^\top X_i.
]

После сортировки (z_i) для каждого центра достаточно найти интервал

[
z_i\in
\left(
z_j-\frac{h}{\sqrt{1+\alpha^2}},
z_j+\frac{h}{\sqrt{1+\alpha^2}}
\right).
]

Стоимость:

[
O((n+J)d)
]

на проекции,

[
O(n\log n)
]

на сортировку,

[
O(J\log n)
]

на интервальные запросы.

Если число кандидатов (C), полные расстояния стоят только

[
O(Cd).
]

Итого

[
\boxed{
O(
(n+J)d
+n\log n
+J\log n
+Cd
)
}
\tag{15}
]

вместо

[
O(Jnd).
]

# 15. Multi-index range search

Необходимое условие ненулевого веса:

[
u^\top\Lambda u<h^2,
\qquad
u=P(X_i-x_j).
]

Если

[
y_i=\Lambda^{1/2}PX_i,
]

то оно эквивалентно

[
|y_i-y_j|<h.
]

Значит, первый screening представляет обычный **exact radius search в (m)-мерном пространстве**.

Для усиленного (Q_r)-условия (6) определим

[
A_r
===

\alpha^2I_r+
R^\top(\Lambda-\alpha^2I_m)R.
]

Тогда

[
L_r(z)
======

h^{-2}z^\top A_rz.
]

Матрица (A_r\succeq0). После преобразования

[
y=A_r^{1/2}Q_rX
]

screening опять сводится к

[
|y_i-y_j|<h.
]

То есть вся proposed hierarchy может быть реализована стандартными exact range queries.

Dual-tree алгоритмы как раз предназначены для pairwise задач такого типа; для range search на cover trees существуют строгие адаптивные оценки и при дополнительных геометрических предположениях линейные оценки времени. ([Journal of Machine Learning Research][1])

Гарантии sublinear search нельзя переносить без условий на геометрию данных. Для exact similarity search известны результаты о деградации metric-tree методов в высокой intrinsic dimension. ([arXiv][2]) Поэтому tree-search стоит применять в размерности (m), (m_s) или небольшом (r), а не в исходном (d=1000).

# 16. Самый дешёвый вариант для твоих текущих размеров: кешировать (D_{ij})

Для

[
n=J=2000
]

матрица

[
D_{ij}=|X_i-x_j|^2
]

содержит

[
4\cdot10^6
]

чисел.

Память:

[
32\text{ MB}
]

для `float64` или

[
16\text{ MB}
]

для `float32`.

После одного вычисления (D) больше ни на одной outer iteration не требуется читать (d=1000) координат для каждой пары.

### Single-index

Одна итерация:

[
z=X\beta:
O(nd),
]

затем

[
s_{ij}=z_i-z_j:
O(Jn),
]

и

[
q_{ij}
======

\frac{\alpha^2D_{ij}+s_{ij}^2}{h^2}:
O(Jn).
]

Получаем

[
\boxed{
O(nd+Jn)
}
]

вместо

[
O(Jnd)
]

после первого шага.

### Multi-index

Вычисляем

[
Z=XP^\top
]

за

[
O(ndm).
]

Затем все

[
u_{ij}=Z_i-Z_j
]

и квадратичные формы:

[
O(Jnm).
]

Итого:

[
\boxed{
O(ndm+Jnm)
}
]

на weights stage.

При

[
d=1000,\qquad m=2
]

это разница примерно между (d)-мерной и двумерной работой на каждой из (4\cdot10^6) пар.

# 17. Если память для (D) нежелательна: early abandoning

Полную норму можно считать блоками.

### Single-index

После (r) координат известно

[
D^{(r)}
=======

\sum_{\ell=1}^{r}
\Delta_\ell^2
\le D.
]

Следовательно,

[
q
\ge
\frac{
\alpha^2D^{(r)}+s^2
}{h^2}.
]

Как только

[
\boxed{
\alpha^2D^{(r)}+s^2\ge h^2,
}
]

остаток координат читать не нужно.

### Multi-index

Используем тождество

[
q
=

h^{-2}
\left[
\alpha^2D+
u^\top(\Lambda-\alpha^2I)u
\right].
]

Для partial norm:

[
q
\ge
h^{-2}
\left[
\alpha^2D^{(r)} +
u^\top(\Lambda-\alpha^2I)u
\right].
]

Одновременно всегда имеется lower bound

[
q\ge h^{-2}u^\top\Lambda u.
]

Поэтому используем

[
\boxed{
L^{(r)}
=======

\frac1{h^2}
\max
\left{
u^\top\Lambda u,;
\alpha^2D^{(r)} +
u^\top(\Lambda-\alpha^2I)u
\right}.
}
\tag{16}
]

Если

[
L^{(r)}\ge1,
]

расчёт пары прекращается.

Worst-case остаётся (O(d)), но ненулевые веса и близкие к границе пары только они требуют все координаты.

# 18. Можно переиспользовать zero weights между итерациями

Обозначим

[
A_k=T_k^2,
\qquad
q_k=\Delta^\top A_k\Delta.
]

Пусть

[
\eta_k
======

|A_k-A_{k-1}|_2.
]

Тогда

[
|q_k-q_{k-1}|
=============

|
\Delta^\top(A_k-A_{k-1})\Delta
|
\le
\eta_k|\Delta|^2.
]

Поэтому

[
\boxed{
q_{k-1}
-------

\eta_kD_{ij}
\ge1
\quad\Longrightarrow\quad
w_{ij}^{(k)}=0.
}
\tag{17}
]

А если

[
q_{k-1} +
\eta_kD_{ij}
<1,
]

то новый вес гарантированно ненулевой.

Это позволяет не пересчитывать пары, находящиеся далеко от moving boundary.

Простое утверждение

[
w_{ij}^{(k-1)}=0
\Longrightarrow
w_{ij}^{(k)}=0
]

в общем случае неверно. В файле (h_k) уменьшается, но одновременно меняются (\alpha_k), (P_k) и (\Lambda_k), поэтому PSD-монотонность (T_k^2\succeq T_{k-1}^2) не гарантирована.

# 19. Mass-aware pruning во время подбора параметра

Есть ещё один способ не считать точные веса.

Пусть для пары известна нижняя граница

[
L_{ij}\le q_{ij}.
]

Поскольку (K) монотонно убывает на support,

[
w_{ij}
\le
K(L_{ij}).
]

При проверке условия

[
\sum w_{ij}\ge L
]

можно вести:

[
S_{\rm exact}
=============

\text{сумму уже вычисленных весов},
]

и

[
U_{\rm rem}
===========

\sum_{\text{необработанные}}
K(L_{ij}).
]

Если

[
\boxed{
S_{\rm exact}+U_{\rm rem}<L,
}
]

параметр заведомо недопустим.

Если

[
\boxed{
S_{\rm exact}\ge L,
}
]

он уже допустим и остальные веса для **feasibility check** считать не требуется.

Это полезно, если всё же оставить bisection по (\alpha): каждая проверка параметра может завершаться задолго до обхода всех (Jn) пар.

Однако после вычисления всех (a_r,b_r) breakpoint-selection из разделов 10–12 сильнее: он устраняет bisection полностью.

## Строго доказанный результат

Для single-index прежнее exact screening условие можно усилить до

[
\boxed{
|\beta^\top(X_i-x_j)|
\ge
\frac{h}{\sqrt{1+\alpha^2}}
\Longrightarrow
w_{ij}=0,
}
]

и это максимальное условие, использующее только эту одномерную проекцию.

Для multi-index

[
(P\Delta)^\top\Lambda(P\Delta)\ge h^2
]

уже максимально сильное условие, если известен только (P\Delta). Более сильное exact условие требует дополнительной проекции (Q_r\Delta), после чего получаем (7). Для manifold естественный (Q_r) уже содержится в идее общего superspace (P_*).

Для алгоритма подбора параметров минимальный допустимый (h) и **максимальный** допустимый (\alpha) минимизируют support весов в соответствующих одномерных семействах. При kernel из `sin-mul.tex` оба параметра допускают exact breakpoint-алгоритм без binary search. HJPS задаёт статистическую structure-adaptive основу такого типа итераций; предложенные здесь screening и breakpoint-алгоритмы являются вычислительным выводом из конкретной формы тензоров и kernel, а не результатом их статьи. ([Project Euclid][3])

Самый сильный оставшийся пробел относится не к корректности, а к **среднему числу surviving pairs**. Без предположений о распределении (X), спектре (\Lambda), (h_k) и (\alpha_k) нельзя доказать, что (C_k=o(Jn)): существует набор данных, где все веса ненулевые. Поэтому асимптотическое subquadratic ускорение всех входов доказать невозможно. Exactness всех приведённых pruning-правил от этого не зависит.
